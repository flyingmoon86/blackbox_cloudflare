# 个人精选照片与私密毕业去向

2026-10-27 按用户确认拆成两个功能，随后按用户授权完成验收并部署。仅网站代码、增量迁移和新公告上线；不修改大作业、final，不用真实队员资料做写入测试。见 [发布记录](releases/2026-10-27-个人档案功能发布.md)。

## 页面与权限

- **精选照片**：个人档案 `/members/:id#member-photos`，与关于 TA、舞台经历、送来的心意并列。只有认证队员和管理员能看到已审核且同意队内展示的照片；游客和普通账号仅看到权限提示，HTML 不包含照片说明、编号、地址。没有时刻标题、日期或毕业字段。
- **照片维护**：本人通过“修改我的信息”或档案照片页签进入 `/profile/members/:id/photos`；管理员通过档案管理进入 `/admin/members/:id/photos`。只需照片和可选说明，明确同意向认证队员展示。本人提交待审，管理员提交视为审核通过。其他队员不能维护。
- **毕业去向**：个人中心“我的毕业去向（私密）” → `/graduation/:id`；管理员后台“毕业去向管理” → `/admin/graduation`。仅本人和管理员可读，其他认证队员也不能读取。公开档案没有毕业去向入口或数据，没有摘要共享按钮。
- **汇总与导出**：仅管理员 `/admin/graduation`、`/admin/graduation/export`。按年份汇总，不向队员提供统计，避免小样本反推。

## 数据模型与兼容

保留已写迁移 0025；新增 0026、0027，按序应用，不重置、不回灌。既存队员 ID、绑定、文件键和历史不变。

| 数据表 | 当前职责 |
| --- | --- |
| member_record / member_record_history | 私密毕业去向及不可修改的版本快照；旧 kind=moment 数据保留，但不再创建或放入新页面 |
| member_record_photo / member_record_photo_history | 旧内部照片及审计，保持原私密访问，绝不自动复制进精选照片 |
| member_featured_photo / member_featured_photo_history | 独立精选照片、可选说明、审核状态、队内展示同意、归档、版本、操作者及历史 |

0026 新建精选照片表，并撤销旧毕业去向共享同意，审计记录动作为 graduation_privacy_split（系统账号 0）。0027 将本轮早期草案列 public_consent 更名为 members_consent，含历史表；仅收窄受众，不公开任何照片。早期已运行的迁移内容保持不变。

毕业去向每人最多一条未归档记录，年级或入队年份不用于推断毕业年份。统计字段独立列，院校、单位、来源、备注使用有长度限制的 JSON。填写界面只选去向，不让用户选择资料状态；原先的未填写、未知、不愿提供记录原样保留，不根据空值补全。填写后直接生效，不再要求核实；旧核实列仅作兼容保留，不参与展示或统计。

## 精选照片写入和文件访问

JPG/PNG/WebP，单张不超过 8MB；检查类型与文件头，不接受任意对象键或 URL，不创建可能公开的 resource 记录。文件头检查不等于完整解码或安全内容扫描。

状态变化：本人上传或修改说明后待审；管理员审核通过且 members_consent=1 才向认证队员展示。撤回同意立即隐藏队内展示；归档退出展示但保留对象和审计。仅管理员可恢复，恢复为待审且不恢复同意。旧版本提交返回 409，不覆盖新值。重复上传编号不重复建档。

文件 `/members/:id/photos/:photo/file` 每次重新校验当前会话和认证状态；游客、普通账号即使取得 URL 也不可读。本人/管理员可看未归档且未拒绝的待审照片，其他认证队员只能看通过且已同意的照片。先授权，再处理 HEAD、Range、If-None-Match、If-Modified-Since 和 If-Range；越权不会读取 R2 或返回 ETag。

档案详情、管理表单、历史和文件均 private, no-store。档案详情不属于导航预取 HTML 缓存白名单；图片不属于公共预热资源白名单。公开首页、列表、搜索不读取精选照片或去向。历史公开头像的权限不变。

上传复用容量预留、对象台账和清理队列：先记清理意图再写 R2，元数据与审计原子提交；失败可重试清理。独立对象键避免并发覆盖。清理服务保护精选照片与旧内部照片的全部引用，包含归档对象。存在任一受限资料或精选照片的档案禁止永久删除，避免丢失审计。

旧 `/member-records` 地址兼容读取私密毕业去向；旧内部照片地址仍只允许本人和管理员，保留审核/归档及原文件访问。新 `/graduation` 不注册旧照片上传/文件路由。旧时刻不显示在当前毕业去向页，也不自动成为精选照片。

## 轻量填写与统计口径（2026-10-27 更新）

填写页直接显示毕业年份、去向选择和相关字段；没有资料状态、核实状态、信息来源、本科履历或层叠“补充资料”。年份和补充信息均可留空。保研/考研显示学校和专业，出国/境显示学校和国家/地区专业，就业显示单位和岗位，创业显示项目/团队和方向，其他显示简短补充，“还没定”不展开附加字段。

使用原生单选和 CSS `:has()` 即时切换，不依赖 JavaScript；不支持该选择器的旧浏览器显示完整字段作为回退。服务端按所选类型接受字段，忽略隐藏类型的值，防止无 JS 提交混入旧答案。切换类型时清除当前值中旧类型的补充答案，历史快照仍保存；原有本科、博士、信息来源字段不在新表单中修改，不会因提交缺字段而丢失。

保存时自动标记已填写，不再核实。统计直接相信已填写内容，与旧 verified 值无关：

- 每人一条当前去向，年度纳入人数为该年未归档记录数。
- 保研率 = 已填写保研人数 / 已填写且去向已确定的人数。
- “还没定”、未建档及历史未填写/未知/不愿提供不进入分母；原有这些状态保留内部值，不在用户表单提供选项。后台合并显示未提供去向人数。
- 缺毕业年份另列；未建立记录另列全局数量，不猜测毕业年份。
- 分母 0 显示“暂无可计算数据”。例如已填保研、考研、就业各 1 人，另有还没定 1 人和历史未知/拒绝/未填各 1 人：纳入 7、确定去向分母 3、保研率 33.3%。不再排除旧的待核实记录。

CSV 仅导出队员 ID、姓名、毕业年份、去向、更新时间；没有资料状态或核实状态，不导出具体院校/单位、来源、备注、照片。仍仅管理员可导出，所有字段转义并防公式注入，超过 10000 条需按年份缩小范围。

## 审计与恢复边界

每次创建、修改说明、审核、撤回同意、归档与恢复均保存版本快照。历史不可修改或删除，当前界面没有永久删除功能。恢复不恢复此前共享同意；重新展示需要显式选择并审核。历史值回退需重新填写生成新版本。撤回展示不等于删除审计、抹去已被合法查看或保存的副本。
