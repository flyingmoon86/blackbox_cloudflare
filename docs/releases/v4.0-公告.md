# 黑匣子网站 4.0 正式发布｜幕布拉开，故事继续

黑匣子网站 4.0 上线了！

从 3.0 到 4.0，我们重新打磨了网站的剧场氛围、作品浏览和档案整理体验，也想邀请大家一起，把属于黑匣子的记忆补充得更完整。

## 这次有什么变化？

- **更有剧场感了。** 首页、作品、队员与鸣谢页面有了各自的舞台背景，配合可以开关的灯光。首次进入网站时，幕布拉开，欢迎入场。
- **浏览更顺手了。** 内部页面切换不再反复播放幕布；加入资源预加载，优化手机图片和作品封面的加载方式，减少重复等待。
- **作品更好找、更好看了。** 作品以画廊式卡片呈现，剧照、简介与演出版本更清楚，查找演职人员和补充对应资料也更方便。
- **队员档案更完整了。** 个人介绍、照片、舞台经历和收到的鲜花分栏展示，可以从队员档案找到参与过的作品，也能从作品认识台前幕后的人。
- **资料整理和反馈更方便了。** 后台完善了档案统计、筛选、分页与选图，方便持续整理大家提交的内容；网站建议有独立入口，反馈正文只送达管理员。

## 也欢迎大家，来把自己的那一页补上

无论是现役队员，还是已经毕业的老朋友，都欢迎回来看看。补一段个人介绍、一张照片、一份剧本，或一条曾经参与演出的记录，都能让这份档案更完整。

入口都放在这里：

- **进入网站：**[黑匣子首页](/)
- **注册账号：**[注册入口](/register)
- **认领自己的队员档案：**[申请队员认证](/profile/member-application)
  先查找已有档案；没有找到自己，再申请新建。
- **完善个人介绍和照片：**[修改我的队员资料](/profile/member)
  完成队员认证后即可填写。
- **补充自己的演出经历：**[作品档案](/productions)
  认证后进入对应作品，在“我是主创”中选择演出版本，填写角色或幕后分工并提交申请。
- **上传剧照、剧本、音频等资料：**[资料提交入口](/resources/submit)
  登录后即可提交，记得选好所属作品和演出版本。普通账号与认证队员提交的资料，审核通过后公开；目前暂不支持视频上传。
- **找不到想补充的作品：**[申请新建作品档案](/suggestions?type=production&source=productions)
  请先登录，再填写作品名称、演出年份和补充说明。
- **发现问题，或有想要的功能：**[网站反馈](/feedback)
  不用登录也可以留言，信息有误、操作不方便、希望增加的功能，都欢迎告诉我们。

舞台上的一场戏会落幕，但一起排练、演出和忙碌过的日子，值得留下来。

**欢迎回到黑匣子，也欢迎一起把黑匣子的故事继续写下去。**
