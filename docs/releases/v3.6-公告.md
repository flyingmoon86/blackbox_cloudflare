# 黑匣子网站 v3.6｜把灯打开，走进剧场

这次更新，我们把网站变成了一个可以开灯的剧场。

- **四个页面，四种舞台。** 首页、作品与资料、队员与剧团、鸣谢换上新的剧场背景。点击舞台灯图标即可开关灯，灯光状态在四个页面间同步。
- **把首页留给剧场。** 首屏移除标题与明星照片，完整展示背景。保留三幕独立切换，放大精选封面，重新安排作品、年份与简介；招新海报和放大预览去掉外框。
- **作品与资料，像一座放映画廊。** 宽幅精选图与图像墙配合图底标题；鼠标经过或键盘聚焦时展开作品信息，手机直接显示。
- **队员名录更清楚。** 保留整页背景，头像按行对齐；缺少头像时以暖纸色底和深墨紫姓氏占位。
- **让剧照跟着视线走。** 推荐项展示最近有剧照的三个作品；鼠标经过时，剧照随指针轻轻移动，手机端直接显示对应图片。
- **页面更轻，阅读更清晰。** 减少搜索区和鸣谢区域的厚重边框，优化背景、文字与灯光的关系，也照顾小屏幕和减少动态效果的使用习惯。
- **后台编辑更好找。** 网站编辑分为“背景图片”“精选大戏”“招新信息”“鸣谢与提示”“颜色”，四组背景集中管理，并提供与前台一致的灯光预览。
- **切换更顺手。** 修复首页从剧团反向滚动返回作品时被防抖拦截的问题，保留同向一次切一幕。

欢迎来黑匣子看看，点亮舞台，也看看我们留下的作品。
