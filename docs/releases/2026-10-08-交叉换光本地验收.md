# 2026-10-08 交叉换光本地验收

- 本地预览：`http://127.0.0.1:8788/#playbill`。

## 本次变更

- 公共栏目切换采用「交叉换光」：导航追光移动，真实旧页面淡去，两束舞台柔光承接等待，目标页面的现有内容分组入场。
- 移除导航下的「准备中」小签；一般等待只显示光影，8 秒以上提供边缘提示和「留在此页」，Escape 始终可取消。
- 入场标记在解析页面头部时准备，避免先显示完整内容再突然隐藏。支持跨文档 View Transition 时衔接导航和光影；普通导航保留 CSS 入场。
- 保留真实页面的文案、列表、剧照、排版与舞台开灯偏好，未引入交互预演中的示例内容。

## 数据与配置

本次未修改数据库、R2 文件、业务记录、Cloudflare 配置或作品详情红幕。后台和管理员页面预览不启用公共换光效果。

本地服务 `.wrangler/navigation-preview-server.mjs` 使用 2026-10-05 完整备份的内存副本和本地文件，仅接受 GET / HEAD，不写入原始备份或生产环境。
