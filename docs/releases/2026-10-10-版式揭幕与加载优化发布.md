# 2026-10-10 版式揭幕与加载优化发布

- 文档类型：版本发布记录。
- 状态：已发布，正式站验证通过。
- 正式站：https://npublackbox.online/#playbill
- 代码提交：`4259db0`（实现版式揭幕转场与匿名导航预加载）。
- Worker：`blackbox-production`，版本 `3d162616-6243-4b73-b7bd-7f20a70cf0b0`。
- 部署前确认的回退版本：`9733a97d-97f9-4efe-97f4-d121c1f99593`。

## 本次变更

- 以方案 2「版式揭幕」替换交叉光，导航追光保留；新页面的标题、内容与图片按实际就绪状态出现。
- 首页先显示，匿名公共主栏目在空闲时顺序预取，悬停、聚焦或触摸导航时优先准备目标；省流与低速网络不自动预取。
- 请求期间旧页保持可读；超过 3 秒显示慢网提示，可重试或取消。单张图片延迟不阻塞正文，失败或离线时保留旧页。
- 仅匿名、无筛选的公开入口使用 20 秒浏览器私有缓存，按 Cookie、Authorization 区分；登录态、后台、筛选、详情、错误与 Set-Cookie 响应继续不缓存。
- 去掉匿名只读列表不必要的 CSRF Cookie 初始化，写入表单的鉴权与 CSRF 校验保持原样；预取脚本纳入内容哈希资源清单。
- 保留真实内容、原生页面导航、历史记录、开灯偏好和作品详情红幕；不插入中间加载页面。关闭 JavaScript 时正常导航。

## 数据与配置

没有数据库迁移、业务数据更新、R2 内容写入或生产绑定调整。本次发布公共导航资源、页面缓存策略和只读列表的 Cookie 初始化逻辑。公开列表更新可能存在最长 20 秒的浏览器缓存窗口；登录态继续使用原生导航及原生网络错误处理。

## 验证结果

- `npm run deploy:check` 通过：格式、类型、145 项后端测试与生产 dry-run；资源清单补齐后再次通过格式和生产 dry-run。
- 本地 10 组浏览器验收已通过，涵盖慢网、断网、HTTP 失败、图片延迟、取消、改选、返回、刷新、减少动态效果、省流和 Cookie 变化。
- 最终版本 `npm run smoke:production` 的 9 项检查全部通过。
- 正式站 18 项专项核验通过：5 个公共入口缓存头与新资源引用、3 个哈希资源线上/本地字节一致、4 类不缓存响应、桌面与手机各 3 次栏目切换。
- 1440px 与 390px 正式浏览器中，预取作品页后的原生导航确认命中浏览器缓存；标题入场、结束清理与导航选中状态正常，无横向溢出或页面脚本错误。
- 本轮未在生产创建账号、上传、审核、导入或修改业务资料；这些写入流程由后端回归测试覆盖，没有重新进行生产写入验收。
- 证据：`.wrangler/editorial-release-check.log`、`.wrangler/editorial-release-assets-check.log`、`.wrangler/editorial-release-deploy-final.log`、`.wrangler/editorial-release-smoke-final.log`、`.wrangler/navigation-editorial/production/verification.json` 及同目录截图。
