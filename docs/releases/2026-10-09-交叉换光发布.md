# 2026-10-09 交叉换光发布

- 文档类型：版本发布记录。
- 状态：已发布，正式站验证通过。
- 正式站：https://npublackbox.online/#playbill
- Worker：`blackbox-production`，版本 `9733a97d-97f9-4efe-97f4-d121c1f99593`。
- 部署前确认的回退版本：`b2adb9a3-bc5b-46f0-9b05-ad6a239fd6e4`。

## 本次变更

- 将用户确认的「交叉换光」接入真实公共页面：上方追光移到目标栏目，旧内容淡去，两束柔光承接等待，目标页面的现有内容分组入场。
- 移除导航下的「准备中」小签；较长等待显示边缘提示，可用「留在此页」或 Escape 取消。
- 保留真实网站内容、排版、舞台开灯偏好、原生页面请求、历史记录、页内锚点和作品详情红幕。页面中间不插入独立加载界面。
- 直接访问、刷新和浏览器返回不重播入场；减少动态效果时关闭换光与位移。

## 数据与配置

本次仅发布公共导航资源与页面装饰结构，没有新增数据库迁移、业务数据更新或 R2 内容写入，Cloudflare 绑定、域名与定时任务配置保持原值。

## 验证结果

- `npm run deploy:check`：格式、类型、142 项测试及生产 dry-run 通过。
- 本地浏览器：14 组检查通过，覆盖 1440px 桌面、390px 手机、320px 减少动态效果，包含慢请求、取消、连续改选、返回、刷新和手机菜单。
- `npm run smoke:production`：正式站 9 项检查通过，包括主要公共页面、健康检查与后台保护。
- 正式站首页、作品、资料、队员、鸣谢均返回 200，并引用新换光结构、样式和页面头部脚本。
- `navigation-light.css`、`navigation-light.js` 的线上哈希资源与本地字节一致。
- 正式站浏览器实际切换作品、队员、鸣谢：入场触发及结束正常，栏目追光正确，无横向溢出或页面脚本错误。
- 证据：`.wrangler/crosslight-release-check.log`、`.wrangler/crosslight-deploy-retry.log`、`.wrangler/navigation-crosslight/results.json`、`.wrangler/navigation-crosslight/production/verification.json`。

首次创建版本时 Cloudflare 返回上传令牌过期（10021），未完成发布。重新建立发布会话后部署成功；正式站验证针对上方成功版本执行。

部署前通过 `wrangler deployments list --env production` 确认旧版本。需要回退本次代码和静态资源时，可将 Worker 回滚到 `b2adb9a3-bc5b-46f0-9b05-ad6a239fd6e4`，随后重新执行正式站检查。

本次没有数据变更，因此未另行执行数据库迁移或数据恢复。此前完整归档备份继续保留，本地预览使用其内存副本。
