## 本次变更

将方案 2「版式揭幕」接入现有公共页面，移除交叉光。首页先显示，后台顺序预取主导航入口；点击后保持旧景可读，目标内容到达再揭幕。3 秒慢网提示、重试、取消和断网恢复与真实请求绑定，单张图片延迟不阻塞正文。

预取仅覆盖匿名无筛选的公共入口，HTML 允许 20 秒浏览器私有缓存，按 Cookie 和 Authorization 区分。只有作品列表管理表单需要的 CSRF 才初始化；资料公共列表不再无故初始化 CSRF Cookie。所有写入鉴权与 CSRF 校验保持原样。缓存不会应用到登录态、后台、个人资料、详情、错误或 Set-Cookie 响应。

原生页面导航、脚本生命周期、历史记录、页内锚点、开灯偏好和作品详情红幕继续使用原有行为；页面未就绪不提前退空旧景，不显示虚构进度。登录态和筛选入口不预取，网络错误仍由原生导航处理。

跨文档转场通过外部样式启用，以符合现有 CSP；导航栏从首次渲染起使用稳定的转场名称，避免切页时短暂闪空。关闭 JavaScript 时回到普通导航，不启动原生转场。

- 后端 145 项测试通过，含新增的匿名缓存允许范围、会话/失效 Cookie 隔离、Authorization、Set-Cookie、错误和后台拒绝缓存检查。

- 类型检查与构建 dry-run 通过。本地验收阶段未执行生产部署或正式站写入。
- 浏览器结果与截图：`.wrangler/navigation-editorial/results.json` 及同目录 PNG。

## 本地复现

启动原有只读预览服务：`node .wrangler/navigation-preview-server.mjs`。运行 `npm run assets:build` 后预览服务自动重载代码。

另开终端执行 `node scripts/check-navigation-loading.mjs --serve-delay`，在 8791 端口把作品入口 HTML 响应延迟 3 秒；代理上游仍是只读的 8788 服务。其他图片与请求保持正常。自动预取已经完成时，点击仍可能直接命中缓存，这是预期行为。

浏览器验收执行 `node scripts/check-navigation-loading.mjs`，可通过 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright 模块，通过 `PREVIEW_ORIGIN` 指定只读本地服务。脚本拒绝非本地上游。
