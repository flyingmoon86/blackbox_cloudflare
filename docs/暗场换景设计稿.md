## 2026-10-09 版式揭幕与真实加载（本地）

用户选择新方案 2，要求同时处理网络等待，并同意首页先可用、主栏目后台分批准备的策略。本次沿用实际内容、排版、作品详情红幕和开灯状态；去掉交叉光装饰。

- 旧页在真实请求期间保持完全可读，导航追光标记目标。等待 450ms 后局部灯光呼吸，3 秒后显示慢网提示、重试和留在此页，Escape 可取消。增强导航请求失败或离线时保留旧页；15 秒超时后允许重试。
- 目标页面就绪后通过原生多页导航提交，标题裁切揭幕、内容分组出现。可视内容图片按真实加载/解码结果单独展开，不让慢图片阻塞标题与正文。首屏图片提升优先级，屏外图片继续懒加载。
- 当前页 load 完成后，以约 1.8 秒间隔顺序预取其余主要栏目 HTML 和最多 3 份缺少的样式；不会预取全部剧照、视频、原图或作品详情。悬停 120ms、键盘聚焦或触摸按下会优先准备目标栏目及其一张舞台底图。低速/省流网络抑制自动预取。
- 仅匿名、无会话 Cookie、无 Authorization、无查询参数的公开入口允许 20 秒浏览器私有缓存；响应带 `Vary: Cookie, Authorization`。这不是 Cloudflare 共享整页缓存。登录态、后台、筛选结果、详情、带 Set-Cookie 的响应和错误仍 `private, no-store`。
- `/productions` 仅管理员需要列表内管理表单的 CSRF；`/resources` 公共列表没有使用 CSRF。去掉这两处匿名浏览时多余的 Cookie 初始化，实际写入表单仍按原规则发放和验证 CSRF。
- 主体仍是原生多页网站。预取只用于浏览器 HTTP 缓存，不注入目标 HTML、不替换应用脚本或伪造历史。登录态/筛选页继续原生请求与原生错误处理；不支持 JavaScript 时普通链接仍可用。
- 原生 View Transition 的声明放在外部样式表中，遵守现有 CSP；直接访问、刷新、返回与减少动态效果模式不强制重播揭幕。

公开入口的文字/列表更新可能有最长 20 秒的浏览器缓存窗口；刷新会重新验证，受保护内容与文件权限检查不变。自动预取是可放弃的加速，不能保证所有浏览器、所有网络都命中缓存。

本地记录见 [版式揭幕与加载本地验收](releases/2026-10-09-版式揭幕与加载本地验收.md)。

## 2026-10-08 交叉换光（2026-10-09 已发布）

用户选择交互预演中的「交叉换光」，并要求沿用真实网站内容。预演中的示例文案、人物、列表和页面结构不进入项目。本次只调整公共导航的追光、退场、等待和入场，不修改作品、队员、鸣谢或首页的内容与排版。

- 导航暖光约 620ms 移至目标栏目；原页面约 420ms 淡去，保留内容轮廓。
- 两束大范围柔光交叉覆盖舞台，底部有淡光池。等待超过 600ms 后，光线轻微呼吸，不显示「准备中」小签，不插入独立加载界面。
- 目标 HTML 到达后，在同一舞台空间按现有内容分组入场：每组约 620ms，错开 65ms，小幅上移 14px，光影约 1000ms 退去。
- 仍使用一次原生文档请求，不额外获取或拼接页面，不设最短等待时间。支持跨文档 View Transition 时保持导航与灯光连续；不支持时使用普通导航和 CSS 入场。
- Escape 可取消；等待超过 8 秒才显示边缘的「加载稍久」提示与「留在此页」操作。读屏从点击时即收到状态通知。
- 返回、刷新与直接访问不重播入场。减少动态效果设置下关闭换光与位移，保留原生导航和取消功能。
- 本地地址为 `http://127.0.0.1:8788/#playbill`，这是现有 Worker 页面与备份内容；`8790` 的三方案预演不是实际网站。

实现和验收见 [交叉换光本地验收记录](releases/2026-10-08-交叉换光本地验收.md)。正式站验证与回退版本见 [交叉换光发布记录](releases/2026-10-09-交叉换光发布.md)。

## 2026-10-06 导航追光与菜单（线上历史）

用户明确要求：顶部用光标记当前导航，切换时换光，下方旧景淡去，新元素再出现；中间不能插入新界面。此前居中的暗场栏目名方案已放弃。

- 导航、纸色和页面空间持续保留。顶部一束暖光打在当前栏目，点击另一栏目后约 380ms 移光到目标处。
- 发起真实导航的同时，旧景约 190ms 淡至低透明度，保留淡淡的内容轮廓。无全屏遮罩、无中央 Loading 画面。
- 页面就绪后，标题、主图、说明和列表按组出现。每组约 380ms，间隔约 55ms，小幅上移并淡入；避免逐字动画。
- 等待超过约 600ms，只在目标导航下显示细光变化与小字「准备中」，旧景持续可见。快速响应不出现提示，也不为了演出效果人为等候。
- 切换过程中允许选择其他导航，后来的选择优先；慢速请求提供取消。网络错误由浏览器的原生导航处理。
- 仅等待必要内容就绪，列表懒加载图片不阻塞入场；使用真实请求状态，不显示虚构百分比。
- 保留浏览器返回、新标签页、下载、外链和页内锚点语义。减少动态效果时关闭移光及元素位移。
- 导航照明与用户保存的舞台开灯/关灯状态分别管理，不自动播放声音。具体作品当前红幕开场未改动。

当前聊天的 `blackbox-nav-light-transition.html` 为早期交互设计稿。
