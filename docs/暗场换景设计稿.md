# 导航追光与景内换场（2026-10-06 已部署）

用户明确要求：顶部用光标记当前导航，切换时换光，下方旧景淡去，新元素再出现；中间不能插入新界面。此前居中的暗场栏目名方案已放弃。

- 导航、纸色和页面空间持续保留。顶部一束暖光打在当前栏目，点击另一栏目后约 380ms 移光到目标处。
- 发起真实导航的同时，旧景约 190ms 淡至低透明度，保留淡淡的内容轮廓。无全屏遮罩、无中央 Loading 画面。
- 页面就绪后，标题、主图、说明和列表按组出现。每组约 380ms，间隔约 55ms，小幅上移并淡入；避免逐字动画。
- 等待超过约 600ms，只在目标导航下显示细光变化与小字「准备中」，旧景持续可见。快速响应不出现提示，也不为了演出效果人为等候。
- 切换过程中允许选择其他导航，后来的选择优先；慢速请求提供取消。网络错误由浏览器的原生导航处理。
- 仅等待必要内容就绪，列表懒加载图片不阻塞入场；使用真实请求状态，不显示虚构百分比。
- 保留浏览器返回、新标签页、下载、外链和页内锚点语义。减少动态效果时关闭移光及元素位移。
- 导航照明与用户保存的舞台开灯/关灯状态分别管理，不自动播放声音。具体作品当前红幕开场未改动。
