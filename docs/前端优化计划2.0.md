这份计划依据用户对 PR #1 设计提案的逐项选择制定。2.0 是本计划的版本，不代表网站已经升级为 Version 2.0。所有未勾选事项均未完成。

目标：把提案中的光效、动效、节目单排版与检票入场视觉融入现有 TypeScript/Hono 网站，保留真实数据、权限与管理能力。分批本地验收，全部确认后统一部署。设计提案只作参考，不整套复制其演示 HTML、脚本和数据。

## 发布限制：先优化，确认可以后再部署

必须依次完成：**优化实现 → 本地测试与可视验收 → 用户确认效果可以 → 用户明确要求部署 → 统一上线与线上验证**。

- “开始优化”“继续”“测试通过”、合并 PR 或推送 GitHub，都不代表授权部署。
- 用户确认某一批视觉效果，只允许继续后续优化，不自动发布这一批。
- 优化期间不执行生产部署、远程数据库迁移、生产配置或正式页面文案修改，也不重新接通 Git 自动部署。
- 历史上已经授权的性能优化上线，不作为本次前端 2.0 的发布授权。
- 完成全部批次后，交付本地预览入口、验收结果、差异清单与未决问题；有关键兼容问题未解决时不能进入发布阶段。

- [ ] 入场淡入只影响视觉，不等待动画才显示按钮；前端脚本失败时正文仍可见。
- [ ] 聚光呼吸限制在首页装饰层，优先 opacity/transform，避免大面积持续 blur/filter 重绘；装饰不接收点击。
- [ ] 首页不在当前幕、页面不在前台时暂停常驻动画；手机低开销呈现，不做多层常驻光效。
- [ ] 送花花瓣数量有限、结束后移除；无闪烁、连续自动播放或全屏遮挡。
- [ ] prefers-reduced-motion 关闭呼吸、花瓣和位移动效，保留操作状态；额外提供“减少动效”本机偏好开关，读取失败时页面仍可用。
- [ ] 保持静态内容哈希缓存；动态页面、账号和待审数据不公开缓存。图片继续走展示图，不复制演示原图作为正式默认资源。
- [ ] 对比改版前后的首屏图片/字体/脚本体积、LCP、布局偏移与交互长任务；出现明显退步先压缩或减少装饰，不用“美术升级”解释掉卡顿。
- [ ] 线上网络和 Smart Placement 是独立变量；比较前端性能时保持后端配置一致，不把换皮收益和网络波动混算。

## 8. 最终验收清单

- [ ] 尺寸：1366×768、1366×640、390px、360px；补测横屏、放大文字和 200% 缩放，必要时切换自然阅读布局，不能裁掉操作。
- [ ] 操作：鼠标、触控板、触屏、键盘 Tab/Enter/Esc、系统减少动画；焦点清晰，弹窗能关闭和返回原位置。
- [ ] 内容：精选/公告/海报为空，中文长姓名/长作品名、缺图、超长正文、同年多版本、无审核待办。
- [ ] 网络：慢网、图片/字体加载失败、提交超时；错误可见，文字可读，不丢输入、不盲目重复提交。
- [ ] 身份：游客、普通账号、认证队员、管理员，以及禁用账号、会话过期、临时密码账号。
- [ ] 安全：CSRF、权限、原件下载、待审可见性、Turnstile 真实成功/失效/重放；浏览器工具不可用时明确记录待验收，不以模拟通过替代。
- [ ] 当前类型、格式、后端回归、数据转换及 production dry-run 通过；针对新增交互增加必要测试，不为纯样式重复写实现镜像测试。
- [ ] 查看实际桌面/手机截图，并检查控制台；不能仅凭 HTML 或构建成功勾选视觉通过。
- [ ] 用户依次确认主题、三幕首页、作品/队员、账号/指南四组本地成果。
