# 迁移验证记录

更新日期：2026-09-09。所有验证均使用本地模拟 D1 和虚拟数据；未连接正式账户、域名、邮件或真实文件。

## 基础与账号

- D1 初始迁移可重复执行，共包含业务表和大文件上传任务表。
- TypeScript 类型检查和 Wrangler 不发布构建通过。
- 旧 Werkzeug `scrypt:32768:8:1` 测试密码可验证。
- 匿名首页、静态 CSS、健康检查、登录、退出和签名会话通过。
- 修正根路由中间件误拦截静态资源的问题；CSS/JavaScript 返回正确类型，不存在的网址返回 404。
- 实际浏览器截图确认米白暖黄色主题和测试须知弹窗正常显示。
- 错误 CSRF 返回 400，错误密码返回 401 且不泄露账号状态。
- 注册会拦截弱密码、两次不一致和重复用户名。
- 修改密码后旧密码失效，`auth_version` 使旧会话立即失效。
- 格式错误的 Markdown 代理变量会由 `scripts/wrangler.mjs` 自动修正。

## 队员与管理员

- 未登录无法访问队员名录；搜索和年份组合筛选通过。
- 首次献花成功，当天再次献花被数据库唯一约束拦截。
- 绑定申请显示档案下拉；新档案申请不包含该下拉。
- 普通账号访问管理员页面返回 403。
- 绑定与新建申请均可通过；驳回理由会显示给申请人。
- 禁用账号后已有会话失效；管理员不能禁用自己。
- 个人中心退出入口可用；网站使用指南与四个主入口并列，管理员额外显示工作台入口。

## 作品、公告与首页

- 管理员可创建编辑作品，添加或删除演员角色和后台分工。
- 普通用户可查看作品，但看不到管理操作。
- 作品详情会列出该作品已审核入库的剧本、剧照、视频等资料；待审核资料不会出现。
- 认证队员可提交演员或后台加入申请；管理员通过后角色进入作品名单，重复申请受到约束。
- 创建作品可导入未归类的待审核和已入库资料，且关联不会绕过审核状态。
- 公告可发布删除，仅登录者可访问，入口位于首页而非顶部导航。
- 精选大戏由管理员从已有作品中选择；未登录点击先登录。
- 剧团信息和联系我们并列；页面文案可编辑并通过锚点直达字段。
- 访客与普通账号、认证队员与管理员使用不同欢迎语；登录首页保留招新、关于我们和四个快捷入口。
- 测试须知会在内容变化后重新显示；认证队员意见可进入管理员收件箱并标记处理。

## 资料记录与审核

- 认证队员可提交资料信息，并归入一部作品或“其他资料”。
- 待审核资料仅提交人和管理员可见，不会提前进入资料库。
- 普通未认证账号提交资料返回 403。
- 管理员可通过或驳回；空理由驳回返回 400，驳回理由会显示给提交人。
- 审核通过后资料进入资料库，列表可进入受权限保护的详情页。
- 资料库按作品和其他资料分区，同一作品的剧照集中为一块画廊。
- 两张剧照连续上传后生成两条独立待审核资料，管理员可分别处理。
- 修正管理员路由中间件作用域，回归确认队员可访问作品和公告，但不能进入管理员工作台。

## 队员档案与帮助页

- 已认证队员可维护本人简介和代表作，不能通过自助表单修改姓名、年份或届别。
- 管理员可从队员详情直达编辑页，维护队员身份信息、简介和代表作。
- 未登录访问帮助页会先登录；普通登录用户只看到队员指南。
- 管理员可看到两份指南，并从每份文案旁直达页面管理的对应字段。
- 管理员保存自定义指南后，管理员指南不会泄露给普通队员。

## R2 文件与图片

- 本地 R2 完成 53MB、两个 50MB 级分片的并行上传与合并。
- 任务快照保留已完成分片；浏览器会复用同一文件的本地任务并从断点继续。
- 缺少分片时完成请求返回 409，上传任务可以取消。
- 队员上传完成后资源保持待审核，审核前下载返回 404。
- 审核通过后完整下载返回 200，Range 下载返回 206 且字节内容一致。
- 管理员可编辑资料元数据、删除 R2 对象；删除剧照同步清除作品封面和首页背景引用。
- 过期任务通过 Cron 测试触发后变为 `expired`，未完成 multipart 已取消。
- PNG 头像上传和读取通过；伪造 PNG 返回 400，管理员移除后返回 404。
- 已审核剧照可作为作品封面和公开首页背景，未登录首页背景读取通过。
- 正式环境的 S3 签名直传代码已通过类型和构建检查；尚需真实 Cloudflare R2 凭据、CORS 和 1–5GB 文件实测。
