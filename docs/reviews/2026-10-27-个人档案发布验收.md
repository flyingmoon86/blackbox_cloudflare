## 本轮检查与修正（Source）

- 七类去向使用各自独立输入，修复切换时“专业”被带成“岗位”、学校字段值混入其他类型的问题。字段顺序遵从类型配置；服务端只读取所选类型，旧表单字段仍兼容；版本历史保留。
- 缩小填写页标题与阅读宽度；照片管理去掉重复说明和嵌套卡片，编辑说明按需展开，管理员添加照片默认折叠，待审优先。个人中心补直达照片入口，身份改用中文。
- 浏览器发现照片同意框受全局 input 宽度影响，挤出手机页面；限定复选框宽度，整个标签仍有 44px 点击区域。档案页签保留横向操作，隐藏多余纵向滚动条。
- 新增 `/admin/member-photos` 集中待审入口，只列有展示同意且未归档的待审照片，分页直达原有审核页面，继续使用管理员校验与 no-store。
- 后台统计去掉重复保研人数列、缩短筛选表单，将口径放在可展开说明里；数据不改口径。
- 完整备份补入两类成员照片的对象引用，包括已归档照片；旧快照没有新增表时仍兼容。补充缺对象拒绝完成的合成测试，修复测试 SQL 重放时间戳不稳定的问题。

## 边界与未验证项

- 手机为响应式浏览器及鼠标/键盘点击，不是实体触屏测试；Safari、200% 字号、实际系统减少动画模式未实测。新填写控件用原生表单/CSS，无新增依赖动画；该源码结论不冒充减少动画实测。
- 未关闭全局 JavaScript；无脚本提交与服务端类型筛选有自动化覆盖，不能据此声称完整无脚本页面验收。
- 真实手机文件选择、慢网/中断的浏览器上传、登录后生产写入和真实队员数据未用于验收。相应上传/权限失败路径由合成自动测试覆盖。
- 生产备份和发布结果单独记在发布记录，不把本地合成预览等同线上实测。
