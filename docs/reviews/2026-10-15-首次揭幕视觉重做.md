# 首次揭幕视觉重做（本地）

仅修改 cloudflare 的首次入站体验，不修改大作业、final、数据库或正式站。站内导航继续原生直切，不出现幕布。

## 设计和实现

- 去掉重复紫色渐变条纹、厚舞台边框及亮中缝。采用深酒红绒布、柔和侧影、米白宋体队名与细金色进度线。
- 新增 `public/images/curtain-velvet-v1.webp`，1536×1024，89,198 字节。由内置 imagegen 生成原创写实纹理，不是实拍视频，也没有下载或使用前述付费参考视频。PNG 仅做 WebP 编码转换，未增加运行时图像依赖。
- 两侧布料以边缘为支点压拢，配合轻微倾斜表现下摆跟随；900ms 揭幕，无最短停留和启动等待。这里只是二维纹理变形，不声称物理布料模拟。
- 图片只在首次幕布挂载时请求，由构建脚本输出内容哈希 URL；不会加入页面就绪判定。慢图、坏图保留 CSS 布料底色，不影响揭幕。
- 清理回退读取 `--curtain-reveal-duration`（约定单位 ms）并加 120ms 余量，避免旧 700ms 清理器截断新动作。保留真实资源进度、10s 准备期限、脚本失败回退和减少动画。

## 本地证据

- `node scripts/check-curtain-visual.mjs`：Edge 1366×768、390×844，共 14 组。正常加载、关键帧截图、纹理失败、纹理延迟 3s、准备脚本失败、减少动画、揭幕中切换减少动画均通过。
- 无暂停计时：桌面首次可测布料边界变化 35.2ms、清理 906.7ms；手机 21.4ms、901ms。测量起点为合成页面调用 `finish()`，位移阈值为 0.5px；每种仅一次采样，不是点击响应或线上性能结论。
- 慢纹理场景在图片仍请求中时完成揭幕；普通减少动画清理约 0.6–0.7ms，准备脚本返回 503 时约 4.2–4.4ms 清理并恢复页面。
- 截图单独将 CSS 动画暂停在 45% 位置，用于观察半开构图；不能把暂停截图作为实时动作计时。实际查看了桌面、手机闭合和半开截图，以及真实 Worker 模板的首次加载截图，文字未溢出，布料图片正常显示。
- `node scripts/check-work-curtain-browser.mjs` 的既有 13 组回归通过：键盘、触屏、慢 HTML、慢封面、重复点击、原生取消、存储禁用、无 JS、减少动画；站内源页/目标页幕布插入及动画均为 0。
- 相关 13 项 navigation-preload 测试、TypeScript 检查通过。本地 8788 首页已返回新幕布和纹理的哈希路径，用户已有标签刷新后仍遵循已进入状态，不重复揭幕。

证据在 `.wrangler/evidence/curtain-visual-v2/` 和 `.wrangler/evidence/native-navigation/`。前者为合成首页；后者为实际 Worker/视图配合合成数据。未验证实体手机、Safari、正式站效果。未提交、推送或部署。
