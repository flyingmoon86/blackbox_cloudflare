# 2026-10-15 站内直接切换修正

用户确认的最终行为：首次入站加载保留幕布；进入网站之后，站内页面直接切换，不再合幕或揭幕。此次要求取代此前站内幕布转场的设计。只修改 cloudflare，本地验收，未提交、推送或部署。

## 修改与原因

旧 `curtain-boot.js` 有两个独立入口：源页点击挂载 `is-covering`；目标页即使已命中 ready 缓存，仍走 `mount("arriving")` 并揭幕。这是“已经加载过仍重复幕布”的直接原因。

现在删除两处站内动画分支、取消幕布按钮和相关 CSS，只允许首次资源准备挂载 `site-opening-curtain`。首次加载完成的 600ms 揭幕保留。恢复手机链接的原生点击高亮。

每个标签页记录已进入网站状态；同源 referrer、历史导航及原有导航标记共同避免站内入口重新触发首次 loading。缓存 ready 或上次超时/部分失败也不再落入目标页揭幕分支。存储不可用时同源 referrer 仍可识别站内跳转。

站内点击保留原生链接和浏览器导航。脚本只暂停可选预取，不调用 `preventDefault`，不等待预取、计时器或动画。取消由浏览器原生处理，后续交互恢复可选预取。无覆盖层、焦点锁定或自定义“取消打开”按钮。

已有手机资源、导航预加载、作品低清预热、渐进封面与列表返回恢复保留。缓存仍可能过期或需要服务器复核，所以不承诺所有导航都没有网络请求；本次消除的是站内幕布及其视觉等待。

## 验收

- Automated：`npm run deploy:check` 通过，格式、类型、175 项测试、生产 dry-run 全部成功；日志 `.wrangler/native-navigation-check.log`。新增测试覆盖已进入、ready、dismissed、同源进入及导航交接时绝不挂幕。
- Rendered：Edge 155.0.4283.45，本机临时 HTTP 服务、真实 Worker/模板、合成数据库和文件。桌面 1366×768、手机 390×844；正常、减少动画、禁用 sessionStorage、无 JavaScript 五组检查通过。
- 四组启用 JS 的冷上下文：首页首次加载各挂载一次幕布，文本为“正在加载黑匣子”，没有“直接进入”；禁用 JS 时原生页面正常呈现。
- 首次完成后，从首页进入作品列表、进入详情、返回列表、切换队员、返回首页、后退及普通暖刷新，持续监测到的站内幕布 DOM 插入和动画次数均为 0。禁用存储组未断言刷新仍不 loading，因为刷新既无可用会话记录，也不能可靠区分新入站。
- 模拟详情 HTML 响应延迟 1.8 秒，源页保持可见，原生请求分别在操作开始后 25 / 25 / 22 / 18 / 14ms 发出（对应桌面、手机、减少动画、存储禁用、JS 禁用）。这是自动化操作到请求的单次诊断值，不是物理输入延迟，也不是页面加载完成时间。
- 封面另延迟 1.8 秒，目标页无需等封面即显示内容，且不挂幕。快速三次点击遵循浏览器原生请求行为；使用浏览器停止加载后可继续导航，无遮罩残留。
- 直接打开详情的八组专项通过：桌面/手机慢图片及延后脚本、脚本失败、boot 失败、CSS 失败、封面失败、无 JS、减少动画。两种视口持续监测幕布插入为 0，无横向溢出。
- 当前用户本地预览 `http://127.0.0.1:8788/` 已刷新到新版本，并实际操作了首页→作品列表→大国之蓝详情→队员；页面正常打开。该轮真实内容浏览用于操作核对，定量结果来自上述合成夹具。

原始证据：`.wrangler/evidence/native-navigation/navigation/metrics.json` 和同目录事件/截图；直接详情检查在 `.wrangler/evidence/native-navigation/first-paint/metrics.json`。首次加载、慢响应仍显示原列表、无幕布详情的代表截图已查看。普通场景未捕获 JS 异常；脚本/素材失败为主动注入。

未验证：实体手机、Safari、正式站。此次没有上线，因此正式站行为尚未改变。
