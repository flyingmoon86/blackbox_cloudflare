# 公告 Markdown 与预览（本地）

> 后续状态：2026-10-18 已按用户授权部署，并更新原 4.0 公告。见 [正式发布记录](../releases/2026-10-18-公告Markdown发布.md)；下文保留本地阶段事实。

范围：cloudflare 网站的公告输入、预览、列表摘要与详情。用户选择“Markdown + 预览”，未授权本轮上线。保留原有数据库、公告 ID、发布和删除地址；不改大作业或 final。

## 实现

- `src/shared/announcement-markdown.ts` 使用 Marked 18.1.1，同一份规则供服务端正文与浏览器预览使用；普通换行启用 breaks。正文标题最小为 h2，页面标题保持 h1。
- HTML 转义、图片只保留文字；链接仅允许本站根路径、锚点、http/https 和 mailto，拒绝可执行协议、协议相对地址、反斜杠、控制字符及带凭据的 URL。链接标签和属性不能注入 HTML。配置中的主站来源经原有 `adminPortal` 校验后用于后台相对链接。
- `src/client/announcement-editor.js` 提供加粗、小标题、列表、插入链接和同步预览。富文本粘贴通过脱离页面的 inert template 解析，只转换允许的语义节点和已校验链接；不把粘贴 HTML 插入文档。只含纯文本的粘贴走浏览器原生行为。
- 预览链接在新标签打开；预览及格式按钮均不提交表单。脚本不可用时保留原生 textarea 与发布按钮，公开页面不依赖编辑脚本。
- 公告列表输出转义后的纯文字摘要，避免显示半截 Markdown；正文保存在既有 content 列，提交长度上限 20,000 字符。已有文本中的 Markdown 语法将按新规则解释，不承诺历史排版逐像素不变。
- 编辑脚本只在公告编辑页加载，经现有构建入口清单打包并生成哈希；没有向首页加入新脚本。已准备 [4.0 公告源文](../releases/v4.0-公告.md)。

## 浏览器实测

工具：内置浏览器，桌面 1366×768、手机尺寸 390×844；后者为响应式视口，不是真机。服务：`scripts/announcement-preview.mjs`，本次回环地址 `http://127.0.0.1:12571`。用真实 Worker 与样式脚本、合成管理员、内存 SQLite/D1 适配和空文件桶；未连接本地真实数据库或生产。

1. 在 `/admin/announcements/new` 填入标题、列表、加粗和站内链接，点击预览。预览显示对应标题、strong、列表和三条可点击入口；与公开正文共用渲染代码。
2. 将带 h2、strong、ul 和两个 a 的 HTML 通过工具的 HTML 粘贴输入，正文转为 Markdown 并保留 `/register`、`/resources/submit`；实际发布到合成 `/announcements/2` 后，游客仍可读取完整排版。
3. 在 390px 公告点击“补充资料”，实际到达 `/login?next=%2Fresources%2Fsubmit`，符合游客登录要求。
4. 选中正文后点“加粗”得到 `**需要强调**`。链接地址中 Enter 只插入 Markdown、保持当前编辑页；Esc 关闭面板并将焦点还给“插入链接”按钮。预览按钮可用 Enter 打开。
5. 编辑页加 `?editor-script=off` 后格式工具和预览不显示，普通发布仍成功，正文由服务端输出链接、段落与换行。此场景只移除编辑脚本，其他全站脚本仍运行。
6. 手机长文本、表格和预览未撑破页面；格式按钮计算高度为 44px。发现全站手机 table 最小宽度 680px 导致公告表格内部横向滚动后，加公告作用域覆盖并复测：表格宽 358.79px，容器 359px，页面无横向溢出。
