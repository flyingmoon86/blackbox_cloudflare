# 管理员工作台主题拆分

## 页面划分

原工作台把待办总览、完整认证审核队列、最近 200 个账号放在同一页；系统信息把地图、分析报告、三条业务流、全部表结构和存储放在一页。主要操作是进入待办、连续审核、管理账号，以及按主题查询系统信息。

采用同级主题页与原生链接，保留黑匣子的米白、深棕和黄铜色。参考明日方舟官网世界观的按主题进入内容组织方式，没有引入滚屏动画或额外框架。

- `/admin`：待办总览，五类业务直接进入各自处理页面；保留历史建议入口与实时数量。
- `/admin/member-requests`：队员认证审核，保留搜索、类别、常用驳回理由、连续处理、校验和失败说明。
- `/admin/accounts`：账号列表和筛选，保留启停、解绑、删除及全部确认条件。
- `/admin/system/architecture`：2.5D 系统地图、分析报告、依赖和部署说明、只读状态。`/admin/system` 保留为这一主题的兼容入口。
- `/admin/system/flows`：业务流程；`?flow=upload/read/member` 分别显示上传审核、资料读取、队员认证，一次呈现一个主题。
- `/admin/system/database`：数据库关系图和选定表字段。搜索缩小表选择范围；一次展示一张表，图中关联表仍可直接选择。`?table=...` 支持刷新与前进后退恢复。
- `/admin/system/storage`：R2 用途、访问方式、连接状态、平台统计可获取性和应用预算台账。

其余已有独立页面（创建作品、新建队员、演职表导入、上传、公告、网站设置、资料管理、作品加入审核、资料审核、建档与建议、导入和审核记录）保留原业务入口。左侧持续提供管理员操作及记录，系统四主题另有固定位置的导航；手机主题导航使用两行布局，后台导航保留键盘可展开方式。

## 跳转与兼容

普通主题链接使用完整地址，服务器直接返回对应内容，刷新和浏览器前进后退无需 SPA 路由。地图的 D1、R2、业务流详情链接跳到相应页面。数据库图使用浏览器历史记录保存所选表。

旧 `/admin#accounts`、`/admin#member-requests` 及系统信息的流程、数据库、存储锚点在脚本可用时跳到新地址；无脚本时仍可从原生导航进入新页面。现有 POST 接口、JSON 审核响应、重定向响应不变，原成功消息地址由 GET 路由转到对应的新页面。

后台提醒浮层默认收起，避免遮挡主题导航；数量、提醒展开、已读和业务跳转能力保留。

## 实现位置与权限

- `src/views/system-info.ts`、`src/routes/operations.ts`：主题页面和按主题返回的只读片段；原不带参数的数据接口保留完整结果。
- `public/system-schema.js`：独立轻量关系图与表选择；只有架构页加载 Three.js。
- `public/system-scene.entry.js`、`public/system-info.js`、`public/system-info.css`：跨页跳转、旧链接兼容和响应布局。
- `src/routes/admin.ts`、`src/views/admin.ts`、`src/views/admin-navigation.ts`、`public/workbench.js`、`public/app.js`：认证与账号独立页面、导航和通知呈现。

全部新增页面仍经过有效管理员鉴权。系统数据接口继续禁止缓存；查询仅用于元数据、连接检查和已有应用台账。没有改动数据库结构、上传/审核/账号服务规则，没有添加外部服务或平台凭证。R2 不可获取指标继续明确标注，未生成容量估算。

## 验证

- 后端 108 项回归通过，覆盖新增各主题页面与查询参数的管理员权限、匿名/普通用户/队员/禁用管理员拒绝访问，以及既有审核、账号、上传和导入能力。
- 本地临时 Miniflare 合成数据：主题导航均可到达；业务流程切换及前进后退；数据表选择、刷新恢复、后退、无匹配提示；过滤后用键盘选择关联表；地图到数据库跨页跳转。
- 实际提交认证通过后待办从 7 变为 6；账号禁用和恢复后回到独立账号页并显示成功提示。解绑与删除通过隔离数据库测试验证。
- 手机 390×844：账号卡片和主题导航无横向溢出，导航可用 Enter 展开；数据库图一次显示一张表，图本身可在容器内滚动。
- 旧账号/存储锚点实际验证可跳到对应新页，浏览器控制台无错误或警告。

预览仅使用本地临时 D1/R2 与合成账号。未部署生产环境。
