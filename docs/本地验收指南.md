# 本地验收指南（第一次运行）

这套步骤只在你的电脑上启动测试网站，不会发布到互联网，也不会连接正式数据库。

## 一、打开项目终端

在资源管理器打开：

```text
D:\大三\blackbox_cloudflare
```

在文件夹空白处右键，选择“在终端中打开”。确认终端提示符最后是 `blackbox_cloudflare>`。

## 二、第一次准备

依次复制并执行：

```powershell
npm install
Copy-Item .dev.vars.example .dev.vars
npm run db:init
```

如果提示 `.dev.vars` 已存在，可以跳过第二条。这个文件只保存本机测试密钥，不会上传 GitHub。

## 三、启动网站

执行：

```powershell
npm run dev
```

看到类似下面的文字即表示启动成功：

```text
Ready on http://127.0.0.1:8787
```

按住 `Ctrl` 点击该网址，或复制到浏览器打开。测试期间不要关闭这个终端。

## 四、按顺序检查

1. 未登录首页能看到“黑匣子永远是你的家”、登录和注册入口。
2. 点击“注册”，创建一个测试账号。密码需要 8–128 位。
3. 用刚注册的账号登录，首页应显示“欢迎回来”。
4. 打开“个人中心”，确认用户名、身份和邮箱状态正确。
5. 先故意输入错误的当前密码，网站应拒绝修改。
6. 再输入正确的当前密码并设置新密码，网站应回到登录页。
7. 旧密码应无法登录，新密码应可以登录。
8. 点击“退出登录”，应回到未登录首页。

测试账号只存在于本机 D1 模拟库，不会出现在 GitHub 或未来正式网站。

## 五、停止网站

回到运行网站的终端，按：

```text
Ctrl + C
```

## 六、只检查代码能否构建

不打开网站时，可执行：

```powershell
npm run typecheck
npm run build
```

两条命令都无报错，表示 TypeScript 类型检查和 Cloudflare 模拟打包通过。`npm run build` 不会发布网站。

## 七、代理地址错误

项目的 npm 命令会自动把误写成 Markdown 链接的代理变量还原为纯网址。如果升级依赖后再次看到 `TypeError: Invalid URL`，请先确认运行的是最新版代码，再执行 `npm run dev`。

## 八、验收管理员审核

1. 用普通测试账号提交一条队员认证申请。
2. 使用管理员账号进入“管理员工作台”，分别测试通过和驳回；驳回时必须填写理由。
3. 申请人重新登录后，应在个人中心看到结果。
4. 管理员可禁用其他测试账号，但不能禁用自己。

## 九、验收作品与演职员

1. 管理员打开“作品与资料”，点击“创建作品”。
2. 填写名称、年份、短介绍和剧情介绍并保存。
3. 在作品详情中从队员下拉列表选择人员，分别添加演员角色和后台分工。
4. 确认两类人员分组显示，并可点击姓名进入队员档案。
5. 编辑作品标题或介绍并保存。
6. 用普通账号登录，确认可以查看作品，但看不到编辑和删除操作。

## 十、验收公告与首页

1. 管理员进入“管理员工作台”，点击“管理公告”并发布一条测试公告。
2. 回到登录后首页，确认公告入口出现在首页内容中，顶部导航没有“公告”。
3. 退出登录后直接打开 `/announcements`，应先跳到登录页面。
4. 管理员进入“页面管理”，编辑首页欢迎语、剧团介绍和联系说明。
5. 从已有作品中指定一部“精选大戏”并保存。
6. 退出登录，确认剧团信息与联系我们左右并列，并显示精选大戏。
7. 未登录点击精选大戏，应先登录；登录后进入对应作品。
8. 管理员登录首页，点击文案旁的编辑入口，应跳到页面管理的相应位置。

## 十一、验收资料提交与审核

1. 用已认证队员账号进入“作品与资料”，点击“提交资料”。
2. 填写标题、类型、所属作品或“其他资料”、原文件名和说明并提交。
3. 打开“我的提交”，确认状态显示“等待审核”；此时该资料不应出现在公共资料库。
4. 用未认证普通账号直接打开 `/resources/submit`，应看到无权限提示。
5. 管理员进入“管理员工作台”，点击“审核资料”。
6. 尝试不填理由直接驳回，网站应拒绝；填写理由后可正常驳回。
7. 队员在“我的提交”中应看到“已驳回”和管理员理由。
8. 再提交一条资料并由管理员通过，确认它出现在资料库并可进入详情页。
9. 详情页当前提示“文件上传将在 R2 接入后开放”，这是迁移阶段的正常状态。

这一阶段只验证资料信息、作品归类和审核权限，不会上传真实视频。1–5GB 文件要在 R2 大文件上传阶段验收。

## 十二、验收队员档案与帮助页

1. 用已认证队员账号打开“个人中心”，点击“维护我的队员档案”。
2. 修改个人简介和代表作并保存；姓名、年份和届别不应出现在队员自助表单中。
3. 返回自己的队员详情，确认新内容和“编辑我的简介与代表作”入口都存在。
4. 用管理员打开任一队员详情，点击“编辑队员档案”，确认管理员可修改姓名、年份、届别、简介和代表作。
5. 普通登录用户从个人中心进入“使用指南”，只能看到队员指南。
6. 管理员进入“使用指南”，应同时看到队员指南和管理员指南。
7. 管理员点击指南旁的编辑入口，应直接跳到“页面管理”的对应输入框。
8. 修改两份指南并保存，再分别用普通账号和管理员账号检查可见范围。

头像上传会随 R2 图片上传一起接入；当前页面会明确提示这一点。
