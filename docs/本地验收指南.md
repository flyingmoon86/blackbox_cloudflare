# 本地验收指南 · Version 1.0

更新：2026-09-13。本轮已发布到正式网站，生产迁移 0014 已完成；本机已经同步完整线上快照并替换旧本地运行数据，直接 `npm run dev` 即可。新电脑才需要初始化。正式状态以 [README](../README.md) 为准。

## 本轮重点验收

1. 注册成功可点“登录并认证队员”；普通账号登录后看到可跳过的认证引导，跳过返回原页面。待审核、已认证队员和管理员不重复提示。
2. 首页第二幕在 1366×768 和低高度窗口查看：正文利用剩余高度，只有确实溢出才显示“阅读完整介绍”；向上滚轮仍回第一幕。手机自然滚动。
3. 管理员进入“页面管理 → 特别致谢”，保存分段文字；鸣谢页应在贡献者上方显示信笺式致谢，留空隐藏。正文按纯文本展示，不执行 HTML。
4. 作品列表精选大戏第一，其余年份倒序，同年份按 ID 倒序，分页后顺序不变；队员默认按账号献花与游客献花总数倒序。
5. 新管理员登录后只能修改临时密码；尝试直接进入后台仍回个人中心。新密码不能和临时密码相同；修改后重新登录，旧会话失效。原有账号不强制改密。
6. 三个正式管理员的临时密码交付文件在本机 `migration-work/admin-handover/管理员临时密码.txt`，不进 Git。本次本地快照已包含三个账号。之后本地和线上改密码互不影响。

自动检查：`npm run deploy:check`。本轮已通过 46 项后端回归与真实 Edge 桌面/手机检查，线上 9 项冒烟通过。

## 启动

在 blackbox_cloudflare 文件夹打开 PowerShell：

```powershell
npm ci
# 首次使用且没有 .dev.vars 时：
Copy-Item .dev.vars.example .dev.vars
npm run db:init
npm run dev
```

不要覆盖已有 .dev.vars，不删除 .wrangler 数据库。浏览器打开 http://127.0.0.1:8787 。本机已有 2026-09-13 线上快照，可用同步时的账号登录；后续不是自动同步。以下提升测试管理员的命令仅供没有账号的新电脑使用。

```powershell
node scripts/wrangler.mjs d1 execute blackbox-local --local --command "UPDATE user SET role='admin' WHERE username='你刚注册的本地测试用户名'"
```

仅用于本机，禁止给此命令加 --remote。退出再登录。不要把正式密码或真实备份提交 Git。需要合成验收内容时参考 test-fixtures 和 scripts/data 的导入工具，不覆盖已有数据库。

## 本轮逐项检查

Version 1.0 后续修正：PC 首页第二幕不允许内部滚动，海报占满右侧可用高度。鼠标移到正文或海报区域，向上滚轮应直接回第一幕；长介绍通过“阅读完整介绍”弹窗查看。认证档案按入学年份降序分组（缺少年级时用入队年份）。PC 横版作品两列、竖版最多三列，横图保持图片比例。

1. **资料库与作品**：PC 可以上下滑动；作品一页最多 12 部，资料一页最多 24 条。照片完整可见，不再被压成细条。翻页和搜索能找到后面的内容，其他资料排在作品后。作品内资料也可翻页。
2. **作品主题**：管理员→作品编辑→作品主题色，输入 HEX 或用色盘，保存后进入详情页。留空保存恢复全站色；其他作品不受影响。
3. **首页第一幕**：标题下没有重复欢迎语；精选大戏可有可无，左下有公告；导航含图标、账号图标直接点击。
4. **首页第二幕**：点击“探索剧团”；没有“关于我们”“加入舞台”小标题，只有正文。大标题可在页面管理修改，显示时去标点。PC 海报完整放大利用右侧，手机自然下滑，海报可点击放大。
5. **页面管理**：仅保留首页图片、精选大戏、第二幕正文、海报、邮箱/QQ群、颜色、测试须知和两份指南。微信/公众号/重复欢迎语等入口不再出现。
6. **选图**：背景、小象、作品封面、海报均使用“备选图片”。点开见缩略图；选择后显示当前图，取消/Esc 不改变选择；空选项可清除。手机也能操作。
7. **认证**：普通账号→申请队员认证，先找已有档案；点“找不到我的档案，申请新建”才显示新建表单；该页不出现已有档案下拉。可返回重新选择。
8. **个人信息**：没有“代表作”输入，已关联的作品自动显示在公开档案。更换头像后应正常显示；新图生成小展示版，旧头像仍能看。
9. **年份**：作品、建档申请、队员档案和筛选选项为 2026—2020。历史 2019 等年份编辑其他字段后不被清空。
10. **手机与键盘**：390px/360px，无横向溢出；底栏不遮住保存按钮。Tab 可操作导航、图片和表单，Esc 可关选图；减少动画下仍可切首页。

## 必须保持的权限

- 游客能浏览公开资料低清图，不能取原件、查看待审资料或进入后台。
- 普通账号可上传，人工审核；认证队员低风险资料直接入库，可疑资料转人工。
- 视频选择时提示测试阶段不支持，不能绕过前端从接口上传。
- 作品 AB 角和一人多角不互相覆盖；删作品后资料转其他资料。
- 管理员改色/选图/审核须检查 CSRF 和权限；旧账号密码仍可用。
