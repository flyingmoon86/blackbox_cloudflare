# 阶段 3：队员名录与认证申请验证记录

日期：2026-09-08

## 已实现

- 队员名录仅登录用户可访问。
- 支持按姓名、届别或代表作搜索，并可按入队年份筛选。
- 队员详情显示简介、代表作和献花数量。
- 同一账号按北京时间每天只能给同一队员献花一次。
- 普通用户可选择“绑定已有档案”或“申请新档案”。
- 选择“申请新档案”后，返回的页面中不包含已有档案下拉框。
- 同一用户只能有一条待审核申请；管理员审核功能在后续后台阶段接入。

## 本地端到端结果

- 未登录访问队员名录会跳转登录：通过。
- 搜索与年份组合筛选：通过。
- 首次献花成功、当天再次献花被拦截：通过。
- 绑定方式显示档案下拉框：通过。
- 新档案方式隐藏档案下拉框并显示新档案字段：通过。
- 新档案申请写入 D1 并显示等待审核：通过。
- 测试后已删除虚拟账号、申请、献花和队员数据。
