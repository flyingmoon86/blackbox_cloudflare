# 网站使用指南

## 第一次访问

未登录时仅展示“联系我们”、登录和注册入口，公告及其直链需要登录。“关于我们”已合并到“联系我们”。注册登录后可以浏览公告、名人堂和资料。建议填写邮箱，并在个人中心完成验证，以便忘记密码时找回。

## 查看队员和作品

名人堂支持姓名或简介搜索、入队年份筛选和分页。点击照片或“查看档案”可阅读完整资料。每个账号每天可向每位队员献花一次，北京时间零点后可再次献花。

从导航“作品与资料”进入“戏剧作品”，可以查看每部作品的简介、演员角色、后台分工、剧本、台本、剧照和视频。点击演职员名字可回到名人堂；队员档案中的“参与作品”也可回到该作品。

“参考资料”保存未归入作品的独立文件。点击资料标题进入详情，再下载。已归入某作品的文件展示在该作品页面，不再列入参考资料。

## 申请队员认证

登录个人中心，选择已有的未绑定档案；如果名单中没有你，可以填写资料申请新建档案。两种方式都需要管理员审核。

首次登录的普通访客会看到个人中心的入队提示红点，第一次进入个人中心后自动消失。审核结果则是另一种提醒：驳回后可以修改资料重新申请，点击“我知道了”才会消除审核结果提醒。

## 完善个人档案

认证队员可以在个人中心修改简介、代表作、届别和头像。未选择新照片时，会保留已保存的头像。

“关联资源库中的作品”支持多选。电脑按住 Ctrl 或 Command 点选；取消所有选择后保存即可解除关联。原代表作文字可以继续保留。需要新增资源时，从导航进入“上传资源”。

## 邮箱与密码

个人中心显示已验证邮箱和待验证邮箱。保存或更换邮箱需要输入当前网站密码；收到邮件后完成验证，才可用该邮箱找回密码。

忘记密码时，从登录页进入“忘记密码”。重置成功后，其他设备的旧登录状态会失效。邮件服务尚未启用时，页面会提示联系管理员；管理员配置方法见《邮箱配置指南.md》。

## 管理员

管理员可通过导航新增队员、发布公告和管理用户。待审核申请数量显示在“用户管理”入口。队员档案可编辑、删除和关联已入库资料；公告在详情页可删除。

### 管理作品与演职员

1. 在“作品与资料 → 戏剧作品”点击“创建作品”，填写名称、演出年份和简介。
2. 在“管理作品”选择名人堂队员，添加演员角色或后台分工。同一人有多项分工时分别添加。
3. 在作品页点击“为作品上传资料”，选择剧本、台本、剧照、视频等类型。旧文件从“参考资料 → 资料详情 → 编辑归类”移入作品。
4. 删除作品档案会将文件保留到参考资料，不会一并删除文件。

### 队员资料上传与审核

队员上传时选择所属作品，或保留为参考资料。提交后进入待审核，仅上传者和管理员能查看文件；审核通过后才会公开给网站内其他登录账号。

管理员从“资料审核”查看待审数量和列表，先打开资料核对内容，必要时编辑标题、类型或所属作品，再选择通过或驳回。驳回必须写明理由。队员从个人中心或作品列表进入“我的上传”，查看审核状态；被驳回时按理由修改后重新上传。

管理员自己上传的资料直接入库。已有旧文件保留原状，迁移后视为已入库、未归类。

### 设置剧团特色与首页背景

进入“剧团设置”，填写剧团/学校全称、成立年份、QQ群、公众号和招新信息。未确定的字段可留空，网站不会展示占位的假信息。

选择一张适合公开展示的剧照作为首页背景，保存后首页自动虚化并增加暗色遮罩。不选新图片会保留原图；勾选移除背景则恢复舞台底色。背景会公开展示给未登录访客，请使用准备好对外宣传的图片。

禁用账号会使其登录状态失效。删除账号或队员会清理对应献花记录，累计鲜花数量随之减少。删除队员或资源也会解除相应作品关联。

## 帮助与页面文案

登录后从导航进入“帮助”，所有登录者可以查看队员指南，管理员还能查看管理员指南。直接访问管理员指南同样检查权限。

管理员进入“页面文案”，按页面编辑首页欢迎语、联系我们介绍、页面简介和两份指南。可选说明留空即可隐藏；两条首页欢迎语必填。内容按普通文本显示，不支持 HTML。按钮、字段标签与错误提示由代码维护。

成员和管理员的默认首页欢迎语为“黑匣子永远是你的家”，普通注册用户为“这里是黑匣子”。“剧团设置”可上传、更换或移除首页背景。

管理员浏览页面时，受“页面文案”管理的文字旁会显示“编辑”。点击后跳转到对应文本框，并自动聚焦、高亮；空白的可选说明保留“编辑（添加文案）”入口。普通用户看不到这些入口。修改后仍需点击“保存全部文案”。

## 首页重点演出

管理员在“作品与资料 → 作品 → 管理作品”点击“设为首页即将演出作品”。同一时间只展示一部，可取消或替换；作品名称会公开展示，完整简介及资料仍需登录。未登录者从首页入口登录后直接进入该作品。删除作品会自动取消首页展示。

公开首页与登录后首页共用“剧团设置”的背景剧照。联系我们已放在首页下方，顶部不再显示；上传资料从“作品与资料”进入。

公告入口保留在登录后的首页，不再放入顶部导航。云端部署评估见《技术与部署方案.md》，当前大文件上传仍限 200MB。

## 新版申请与展示

注册时打开“我是队员！”并勾选一并申请，可认领已有档案或申请新建。填写一句台词，也可用后台分工、排练经历替代；仅本人和管理员能查看。旧待审申请须在个人中心补填后才可通过。

管理员在“管理作品”选择本作品已审核剧照作为封面，提供横向 16:9／竖向 3:4；首页可切换左图右文／宽幅叠字。公开宣传简介独立于内部简介，首页仅向未登录者展示封面、名称和宣传简介；登录后可展开“全部演员”。

首页下方由剧团设置统一管理：左侧名称和介绍，不显示成立年份；右侧招新与联系方式。关闭招新会隐藏要求和安排。原页面介绍已迁移，首页快捷编辑转到剧团设置。

帮助页按任务分组，每条旁的“编辑本条”可修改标题和步骤。原来手工编辑的指南保留为原有内容条目；其他页面文案保存不会覆盖帮助条目。
