# 开发维护

## 系统与修改入口

主站和独立后台共用一个 Cloudflare Worker（Hono）、D1 数据库及 R2 文件存储。静态文件由 Static Assets 返回。路由验证请求和权限，服务层处理业务，视图输出 HTML；用户文本输出前转义。后台入口门禁不能替代操作本身的鉴权。

- 请求装配：`src/index.ts`、`src/middleware/`；登录和会话：`src/routes/auth.ts`、`src/auth/`。
- 页面：`src/views/`；统一导航和资源装配：`layout.ts`；共享 HTML 与小组件直接从基础模块引入，避免经兼容 `src/views.ts` 反向循环依赖。
- 作品/演出版本：`src/routes/productions.ts`、`src/views/productions.ts`；公开/隐藏规则：`src/services/production-visibility.ts`。
- 资料/上传/审核：`src/routes/resources.ts`、`uploads.ts`；文件读取、容量、清理和审核在 `src/services/`、`src/storage/`。
- 队员：`src/routes/members.ts`；精选照片：`member-photos.ts` 路由与视图、`member-photo-storage.ts` 服务；去向：`member-records.ts` 路由/服务/视图。
- 公告：`src/routes/content.ts`、`src/shared/announcement-markdown.ts`；保留转义、链接协议白名单和正文长度边界。
- 演职导入：`src/routes/credit-import.ts`、`src/services/credit-import/`、`templates/`；保留 v2 模板及 v1 兼容读取、人工匹配与回滚。
- 增量结构：`migrations/`；测试/工具：`scripts/`；本地运行状态：`.wrangler/`。已执行迁移不能改写，不能把运行状态或真实备份当作缓存清空。

Worker 是服务器程序，D1 保存记录和权限，R2 保存文件，Static Assets 保存公开脚本/样式。D1 与 R2 没有跨服务原子事务，文件删除通过持久清理任务恢复重试。

## 当前业务规则

作品可有多个演出版本，演员、分工和资料要归属正确版本；一个作品保留一张卡片。AB 角与一人多分工允许，只有作品、版本、队员、类别、角色完全相同才重复。非作品资料可存在，新剧照必须归属作品与版本；剧照在作品中查，资料库列其他文件。

游客浏览公开档案、批准资料的低清图/封面，可限频献花及匿名提建议。普通账号可下载可访问资料、上传、申请作品与队员认证；认证通过后才可改本人档案和申请演职分工。认证优先绑定已有档案，再申请新建；贡献者不自动取得队员身份。

管理员上传直接入库，普通账号与认证队员上传一律人工审核；不存在低风险自动入库。新视频上传关闭，保留历史视频读取。文件内容检查不等于恶意内容识别。上传保留分片幂等、租约、容量预留、完成重试与可恢复清理。`UPLOAD_MODE=proxy` 明确走 Worker，`direct` 要求完整签名直传配置，不能缺配置就自动切换；旧任务沿原模式继续。

私有文件逐请求鉴权，先于 HEAD、Range、304 和文件读取；禁止仅靠前端隐藏入口。隐藏作品不能泄漏到资源下载/预览。待审资料仅提交人和管理员可见，原件及完整剧本/媒体需登录。

个人精选照片须审核通过且同意队内展示，仅认证队员和管理员可见；撤回、归档及认证撤销应立即生效，恢复归档不自动恢复同意。毕业去向独立维护，仅本人和管理员可见，保存直接生效，不要求核实，不允许共享摘要。保研率分母为已填写且已确定去向的人数；“还没定”、未填、未知及拒绝提供排除，分母为零不显示虚假比例。旧内部照片和历史记录不自动转换成新精选照片。

建议正文、邮箱不公开；署名遵循同意，提交建议不会自动加入鸣谢。删除/解绑账号保留适用的档案和已审资料，不删除当前或最后一位管理员；会话权限每次检查。临时管理员首次登录强制改密，后台与主站 Cookie 各自独立。

## 批量上传、审核与导入

上传初始化响应直接包含空分片列表，客户端无需再次查询新任务状态；恢复既有任务仍查询服务器。代理模式直接调用分片 PUT，省去返回固定地址的中间请求；该 PUT 保留身份、CSRF、作品可见性、分片大小和任务租约校验。直传模式继续逐片请求签名地址，旧地址接口保留兼容。请求数量减少不等于已测得生产吞吐提升。

上传后端将任务归属及作品可见性合入每次请求的查询，不能跨请求缓存授权结果；创建任务时同时核对作品与版本。分片记录和本次租约释放在同一 D1 batch 提交，预览元数据与解锁通过同一 UPDATE 保存；失败或租约已换人时不能报告成功、覆盖进度或释放其他请求的锁。完成上传复用 R2 合并返回的元数据，响应丢失时仍查询对象确认；历史资源关联、容量预留转正式占用、资源创建和任务完成保留原子提交，已释放租约不重复解锁。按原对象键恢复历史资源和核对共享引用使用 `resource(filename)` 非唯一索引，不能为性能去重或删除历史记录。

`node scripts/measure-upload-backend.mjs` 按剧照、剧本、音频及其他资料，分别测量管理员和队员的上传链路；记录 D1 绑定往返与 batch 内语句数、R2 调用数及查询计划，使用 `EVIDENCE_DIR` 保存优化前后结果。合成数据测量只说明请求开销，不能替代真实网络吞吐或生产计费测量。

资料上传按相同类型、作品及版本组成一批，串行处理文件与分片；批次开始后归属字段锁定。浏览器按账号在 localStorage 保存任务编号和逐项结果，不保存文件内容；刷新后需重新选择原文件，只续传待传或失败项，成功项不会重复建档。可以在当前文件完成后暂停，或在空闲时跳过、取消单个任务；新建一批会替换本机这一批的记录。支持 Web Locks 的浏览器会阻止同账号多个标签页同时处理上传，旧页面需刷新最新进度。存储不可用时提示保持页面打开；额度耗尽时按 Retry-After 暂停，不绕过服务端限频。既有未完成上传任务仍可恢复。

资料、队员认证与演职申请共用勾选审核，每次最多选择 50 条当前可见项；操作前明确确认已逐项核对，驳回须填写理由。客户端串行调用原审核接口，每项仍独立检查权限、CSRF、状态和审核记录；状态冲突保留待核对项，登录失效、服务故障或响应不明停止后续发送，不自动重放审核。资料页可预览待审图片、打开详情并按提交人或演出版本搜索；处理完本页后从筛选结果第一页补充待办，避免偏移分页漏项。当前标签页保留最近一次处理结果，可导出已确认、需核对和未执行的编号；持久审核依据仍是服务端审核记录。

演职员导入的未提交匹配选择按账号、批次和服务端修订号暂存在 sessionStorage，搜索候选档案或刷新时恢复；服务端修订变化后丢弃旧选择。暂存仅限本标签页，必须点击保存才写入服务器，不代替原有预览、确认及回滚流程。

`node scripts/check-bulk-workflow.mjs` 用合成账号、内存数据库和模拟文件存储验证批量上传恢复、跨页审核和导入选择保留，浏览器执行真实页面与 Worker。可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 模块，通过 `EVIDENCE_DIR` 指定任务证据目录；这类本地测试不代表生产容量或真实网络吞吐。

## 页面与构建

维持 Hono 服务端 HTML、原生 JS/CSS，围绕真实剧照、克制大字、细线和留白维护，不引入前端框架。主站桌面首页分场景；手机自然浏览。作品、资料、指南和长表单允许滚动，不套用旧“全站禁止滚动”。颜色遵循严格 HEX 主题，保留危险/成功语义。键盘、触屏与减少动画下功能可用；视觉变更实际检查桌面和手机，不能用源码推断代替渲染。

浏览器模块在 `src/client/`，入口名单在 `scripts/client-entries.mjs`；改源码后运行 `npm run assets:build`。生成的 `public/*.js`、`public/assets/` 和 `src/generated/` 不手改。`public/system-scene.entry.js` 同样经构建输出。其他未迁入模块的 CSS/JS 仍在 `public/` 维护。新增静态资源按需加入 `scripts/build-assets.mjs`，通过 `assetUrl()` 读取哈希路径；保留旧哈希文件供已打开页面使用。

修改后先跑相关测试、类型、格式；提交前的完整检查见 [发布与恢复](发布与恢复.md)。涉及权限时按游客、普通账号、本人、其他队员、管理员检查，使用合成数据。HTML、直链、导出及条件请求均需覆盖。

### 三维档案

公开的作品档案、资料库和三维档案通过页内三项导航切换，共用画廊布局；三维页归属「作品与资料」，桌面主导航和手机底部入口同步高亮。页内链接不触发模型或渲染引擎预加载，后台私有预览保持独立入口。

管理员在「三维档案」中新建草稿、编辑标题和简介、排序，并可关联作品及其演出版本。模型接受二进制高斯 PLY 或压缩 PLY，最大 512 MiB，支持分片续传。封面由浏览器转换为 JPEG。模型和封面上传完成后先进入待发布状态，管理员可以预览，发布时再一起切换。下架保留档案，游客无法继续通过文件链接读取。关联隐藏作品的场景也从公开页隐藏。

D1 保存场景和发布状态，R2 保存模型和封面。迁移 0029 保留场景 03、05 的现有 ID 和 R2 对象键，迁移 0030 复用上传任务存储。预览和上传逐请求检查管理员权限，公开文件先检查发布状态和关联作品可见性，再处理 HEAD、Range 和条件请求。备份核验包含当前和待发布文件。开发环境默认启用公开页，生产由 THREE_D_ARCHIVE_ENABLED=true 开启。三维页按需加载渲染模块，不参与首页预取。

观看窗口优先使用可用画布，标题和工具悬浮，帮助默认收起。只有点击打开或重试才并行下载模型和加载引擎；封面覆盖下载与首帧准备阶段，完整画面准备好后再开放操作。关闭立即中止请求并释放渲染器，不预加载其他场景。标签页最多缓存最近打开的一个、32 MiB 以内的公开文件 Blob；复用前必须发 HEAD 核对当前权限和 ETag，不缓存管理员预览，不持久保存解码几何。替换和下架后不能继续复用旧缓存。

无损传输副本按 `<原对象键>.transfer-<原对象 ETag>.gz` 存放在 R2。客户端支持解压时请求 `?transfer=gzip`；服务端先核验场景和源对象，再读取匹配副本，缺失时自动回退原 PLY。Range 保持原 PLY 字节语义。副本必须离线生成并解压核对 SHA-256，不能在访客请求内压缩大模型。`node scripts/prepare-three-d-transfers.mjs` 为既有 03、05 场景只读核对线上原件并在任务 artifacts 生成副本、清单和容量台账 SQL；上传副本、登记容量和部署仍遵循发布流程。副本随旧原件保留用于回退，完整 R2 备份包含它们。后台新增模型当前直接使用 PLY，不自动生成 gzip 副本。

`node scripts/measure-three-d-compression.mjs` 比较无损压缩体积；`node scripts/measure-three-d-browser.mjs` 使用真实模型、合成存储、限速网络检查下载/初始化/首帧、缓存失效、重试、关闭取消和手机尺寸画面，`--checks-only` 跳过限速对比，`--production` 仅匿名读取已部署站点。支持 `PLAYWRIGHT_MODULE` 和 `EVIDENCE_DIR`。Performance API 中 `three-d-load` 仅供本机测量，不上传遥测；流式解析与下载重叠，下载后剩余解析时间不是总解析 CPU 时间。模拟手机尺寸和桌面合成帧不是实体手机帧率。


### 首次准备与本地导航

公开导航范围由 `src/shared/navigation.ts` 统一维护。`navigation-preload.js` 首次读取匿名页面，等待页面内容、图片解码、样式、页面增强脚本与字体准备完成，再结束幕布。不能用 sessionStorage 中的“进入过”标记代替实际缓存；刷新会重新准备，站内已准备页面切换不再展示幕布。导航准备复用已就绪样式；启动前加载失败的样式在首次使用时先安装监听再重试，重试失败如实计入未准备项，取消后不再发起新的样式或脚本加载。超时、素材或本站脚本失败必须解除遮罩，并保留未缓存链接的原生跳转；Cloudflare 等注入的可选跨域统计脚本失败不得中止准备。

`src/client/navigation/` 管理资源与同步路由：常驻页眉，替换 main，维护 URL、标题、焦点、滚动及浏览器历史。`public/page-runtime.js` 为页面增强注册初始化与清理函数；全局事件用 scope.listen，观察器/动画用 scope.dispose 清理，不重复执行整份页面脚本。切换已就绪页面不得发起 fetch 或等待动画、计时器。

准备时并行请求公开入口 HTML；仅带服务端 public-v1 标记且未登录的当前文档可直接复用，登录态仍匿名请求，不能缓存个性内容。每页样式与图片并行，字体等待样式就绪，图片下载/解码共用最多 6 个任务的队列，重复 URL 共用结果。完成后先让闭合幕布与页面稳定绘制，再播放完整拉幕；双翼只用起止两帧和一条全程缓动，避免多段关键帧反复起步刹停；双翼只做三维平移，纹理不缩放或斜切；揭幕时取消双翼外阴影以免尾部残影，保留布面内侧光影，背景仅渐变透明度，等待两扇布都结束后移除，兜底按实际 CSS 动画时长计算，不能用固定两秒截断或由背景渐隐提前清理。可选纹理解码失败时保留 CSS 布面，揭幕期间不得突然补入纹理；减少动画直接进入，准备完成后 Esc 可跳过揭幕。幕布的 CSS 兜底时间必须晚于准备超时与脚本兜底，准备完成时重置兜底隐藏；幕布背景样式须与通用 dialog 主题隔离，不能让通用面板底色盖住首页。`scripts/check-curtain-opening.mjs` 验证桌面/手机准备与完整揭幕、慢加载、长动画和减少动画，并输出帧采样、截图与回归录屏；判断播放观感另用 `scripts/capture-curtain-preview.mjs` 采集实际合成帧及时间戳，保留采集频率与独立画面数，再生成 60fps 预览，不能把低帧率录屏升帧作为网页流畅证据；`scripts/check-opening-experience.mjs` 验证长加载、透明揭幕、减少动画及前后耗时；`--production` 仅在测试浏览器中替换脚本和样式，使用公开线上响应比较，不代表部署。

HTML 响应声明本站的空 `Speculation-Rules`，避免 Cloudflare Speed Brain 再注入鼠标悬停/触屏预取。发布后运行 `node scripts/check-production-navigation.mjs` 做匿名只读检查，分别记录联网与断网的请求类型及用途；本地环境不能复现平台注入行为。

页面快照与匿名图片 Blob 只保留在当前标签页内；`navigation-worker.js` 只持久缓存含内容哈希的公开静态文件/字体，最多保留 256 项，不拦截 HTML、动态图片、API、HEAD、Range、带认证头请求。登录/个人中心会通知其他标签页失效导航状态。服务端始终检查私有照片、去向与写入权限。公开快照在本次浏览中保持一致，刷新获取新内容；搜索、翻页、详情和个人/管理功能继续联网，不承诺离线刷新或全站离线编辑。新增公开入口先验证匿名响应契约，不能放宽私有页面缓存规则。

验收运行 `node scripts/check-local-navigation.mjs`：使用内存合成数据和真实 Worker，检查桌面/390px/减少动画、联网与断网导航、键盘触屏、返回与连续点击、三种登录角色、直接进入与刷新、存储禁用、无 JS、脚本及图片失败。记录请求数量、同步内容替换时间和双 requestAnimationFrame 采样；双帧采样不是屏幕实际呈现时间，也不能拿本地数值承诺线上设备性能。浏览器结果与截图输出任务 artifacts。手动预览可运行 `node scripts/navigation-fixture.mjs`（默认回环端口 8791，仅合成数据）。

## 常见排查

- 上传后别人不可见：查审核状态、作品可见性与版本归属。无法预览/下载：先查登录与权限，再查对象是否存在，不放宽鉴权来掩盖故障。
- 页面没更新：检查改的是源码还是生成文件、资源构建是否执行以及引用哈希；不要直接修补构建输出。
- 本地正常、线上未生效：本地迁移不作用于生产，Git 推送也不是部署。先查发布记录，不自动迁移或覆盖线上数据。
- 写入请求超时或结果不明：先刷新/只读查询核对状态，再决定重试，避免重复提交。
- 登录/后台异常：查主机、账号状态、会话和强制改密要求，不打印 Secret、Cookie 或密码。
- 构建失败：分清依赖、类型、格式、测试和配置错误。缺少浏览器/编译工具只能说明未验证，不能声称功能或视觉通过。
