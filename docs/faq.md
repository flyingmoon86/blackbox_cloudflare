# 常见问题与故障排查

> 遇到问题先在这里找。没找到时按「排查思路」一节自查，或查 [架构](architecture.md) 与 [验证记录](验证记录.md)。

## 网站使用类

### 上传的文件为什么访客看不到？

文件进入 R2 **不等于公开**。资源须已批准；有关联作品时，该作品还须可见。未关联作品的历史资源按自身审核状态判断，资料详情和下载仍遵守登录规则。常见原因：

1. 还在等审核（管理员或低风险规则才自动批准）；
2. 所属作品是隐藏的；
3. 关联的作品记录缺失。注意：没有关联作品不等于作品记录缺失；新上传仍必须选择作品和版本。

### 为什么视频传不上去？

视频上传目前前后端都关闭。历史视频仍可读取，但不能新传。

### 上传报「文件太大」？

上限：照片 20 MB、剧本 50 MB、音频及其他 100 MB（单个分片 50 MB）。

### 上传报「网站文件空间已接近 9GB」？

网站有约 9 GB 的软件预算（按已存文件 + 预留空间计算）。需要管理员清理不用的文件后才能恢复上传。这不是 R2 桶的实际容量，R2 本身可能还有空间。

### 上传到一半失败了，会留垃圾文件吗？

失败上传会登记进清理队列，由每小时的定时任务重试删除。如果发现「数据库里没有、桶里还留着」的文件堆积，检查定时任务是否正常运行（见下）。

### 批量导入演职记录提示整批失败？

重复或非法条目会导致**整批回滚**，不会只写入一半。检查表格：一次最多 50 行、必须统一选版本、去掉完全重复的条目（作品+版本+队员+类别+角色完全相同才算重复）。

## 开发类

### 本地改了数据库结构，线上没变？

本地迁移不会自动作用于生产。发布时要显式执行 `npm run db:production:migrate`（步骤见[本地验收指南](本地验收指南.md)）。

### `git push` 了怎么没上线？

发布不由 git 触发。要主动跑 `npm run deploy`。这是有意设计：上线是独立决策。

### npm 命令报 Node 版本错误？

需要 Node.js 24 或更新版本。

### 后台登录报错 / 进不去？

- 后台是 `admin.npublackbox.online`，普通账号**设计上就进不去**，不是故障。
- 临时管理员首次登录必须改密，改密前其他操作会被阻断。
- 主站和后台首次要**分别登录**，会话不互通（Cookie 仅限当前主机）。

### CSRF / 403 报错？

写入操作要求同源 + CSRF 令牌。从别的页面或脚本直接 POST 本站接口会被拒。请从本站页面正常操作。

### 部署检查不通过，提示「正式域名仍是占位值」？

`wrangler.jsonc` 里的 D1 database_id、R2 桶名、域名仍是占位值时**不会部署**。按 README/验收指南填写真实 Cloudflare 资源信息（只填域名，不含 `https://`）。

## 排查思路

按请求走向逐段排查（细节见[架构](architecture.md)）：

```
静态文件问题？ ──► 看 public/ 和构建产物（npm run assets:build）
页面显示问题？ ──► src/views/ + src/routes/；先用本地 npm run dev 复现
数据不对？     ──► 查 D1：migrations 是否应用、记录状态（审核/可见性）
文件 404/403？ ──► 先查 D1 资源记录和权限，再查 R2 对象是否存在
                 （权限判断在 D1，不在 R2）
上传问题？     ──► 查 upload_task 表状态 → 清理队列 → 容量台账
定时任务没跑？ ──► 清理队列（file_cleanup_task）是否堆积
```

### 日志能查到什么

有：请求编号、路由、状态、总耗时。
没有：逐条数据库查询耗时——**不能**用日志判断哪个查询慢。

### 测试怎么跑

```bash
npm run test:backend    # 后端测试
npm run deploy:check    # 全套检查（不发布）
```

### 只想验证线上基本活着

```bash
npm run smoke:production
```

通过只代表公开页面能响应，不代表登录、上传、审核等流程正常（那些要人工点一遍）。

## 还没答案的问题

- R2 直传线上是否启用 → 需查环境密钥，见 [验证记录](验证记录.md)。
- 自动审核规则的业务依据 → 没有完整记录，改规则前问负责内容审核的人。
- 备份/恢复的完整流程 → R2 备份待建立，见 [验证记录](验证记录.md) 未办事项。
