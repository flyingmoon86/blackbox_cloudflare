# 产品与权限规则

更新日期：2026-09-09。本文只记录已经确认、当前仍有效的规则。

## 访问范围

- 未登录：首页、登录、注册。首页包含精选大戏预告、剧团信息和联系我们。
- 未登录不能查看公告、队员档案、完整作品和内部资料；从精选大戏进入时先登录，成功后回到该作品。
- 顶部导航不显示公告、上传资源和联系我们。公告入口在登录后首页；上传入口归入作品与资料；联系方式放在首页下方。
- 登录用户：公告、队员名录、作品、获准资料和顶部“网站使用指南”。
- 认证队员：在普通用户基础上可维护自己的档案、提交资料、申请加入作品并提交网站建议。
- 管理员：审核队员认证、作品加入申请、资料和网站建议，管理账号、队员、作品、公告和页面文案；顶部单独显示管理员工作台。

## 首页与内容

- 访客和未认证普通账号默认显示“这里是黑匣子”；认证队员与管理员默认显示“黑匣子永远是你的家”。两类欢迎语都由管理员编辑。
- 访客首次进入显示管理员可编辑的测试须知；确认后不再显示，须知内容更新后重新显示。
- 登录后的首页保留公告、四个快捷入口、招新和关于我们；认证队员可从关于我们进入意见箱。
- 剧团信息和联系我们并列，充分使用横向宽度。
- 管理员在页面文案附近看到编辑入口，直接跳到页面管理的相应位置。
- 管理员从作品中手动指定一部精选大戏；首页背景与管理员设置的同一张剧照共用，图片上传在 R2 阶段实现。
- 公告不出现在顶部导航，未登录也不能通过直链查看。

## 队员与作品

- 申请认证可选择绑定未被认领的档案，或申请新建档案。
- 新建档案模式不显示已有档案下拉框。
- 核对信息可填写台词、后台分工或排练经历，仅本人和管理员可见。
- 管理员审核通过后绑定档案；驳回必须给出理由，申请人可在个人中心确认结果。
- 作品记录简介、年份、宣传短句、演员角色和后台分工；人员从已有队员档案中选择。
- 认证队员可在作品详情自由填写演员角色或后台分工并申请加入；管理员通过后写入演职员名单，驳回必须说明原因。
- 管理员创建或编辑作品时，可将未归类的待审核或已入库 ARCHIVE 资料关联到作品；关联不会自动通过审核。
- 封面只能从该作品已审核的剧照中选择，可选横版 16:9 或竖版 3:4。

## 资源与文件

- 管理员创建和编辑作品、指定演员与后台分工。
- 认证队员上传资料并选择所属作品，管理员审核通过后才进入资料库。
- 剧照可一次选择多张，每张独立保存并分别审核；同一作品的已入库剧照集中显示为一块剧照画廊。
- 资料库按作品分区；未归类资料集中显示在“其他资料”。作品详情反向展示所有已入库关联资料。
- 单个视频经常为 1–5GB，总量预计约 100GB；必须由浏览器分片直传 R2，不能经过 Worker 中转。
- 下载前由 Worker 检查登录、审核状态和权限。
