# 产品与权限规则

更新日期：2026-09-11。前端公测规则已联合后端优化发布，生产已开放下述游客浏览范围。

## 访问范围与首页（已上线公测版）

- 游客可浏览首页、作品及详情、队员、已审核资料展示图、公告、队员指南和鸣谢；下载及完整资料预览必须登录。
- 普通账号登录即可提交资料和申请创建作品；申请认证后才可修改绑定队员资料、申请加入作品。所有管理员接口仍单独鉴权。
- 顶部按作品与资料、队员与剧团、指南与鸣谢、了解黑匣子、账号分组下拉。手机点击展开，并保留底部导航。
- 首页用管理员主图 → 精选作品图 → 最新审核剧照回退，只加载展示图。主视觉叠加欢迎语、可选精选作品和左下公告；第二幕为剧团介绍/招新和联系页尾。小象可由管理员指定。
- PC 全站外框固定，列表分页，内容过长可内部滚动；手机自然滚动，减少动画设置关闭转场。
- 测试须知确认一次；文案变化后再次提示。管理员仍可就地跳转页面管理。
- 全站模糊剧照背景与作品、队员卡片保留。

## 网站贡献者

- 游客可以昵称提交建议并选择不公开；登录者以账号名署名，队员另显示姓名。不公开邮箱或建议正文。
- 新建议表单保存成功后原子创建贡献记录和事件；旧建议不追授。
- 管理员可主动授予、撤销或恢复资格。被撤销者不能通过再次提交自行恢复。
- 公开贡献者显示于鸣谢；队员另显示档案标签。资格不赋予管理或队员权限。

## 队员与作品

- 申请认证可选择绑定未被认领的档案，或申请新建档案。
- 新建档案模式不显示已有档案下拉框。
- 核对信息可填写台词、后台分工或排练经历，仅本人和管理员可见。
- 管理员审核通过后绑定档案；驳回必须给出理由，申请人可在个人中心确认结果。
- 管理员可直接建立未绑定账号的队员档案，供历史展示或让注册者以后申请绑定。
- 队员名录以头像铺满的人物剧照卡展示；桌面端悬停或键盘聚焦时图片快速虚化并上滑显示简介与入口，手机端始终显示精简信息。整张卡片可进入档案。
- 管理员可解除普通队员账号与档案的绑定。解绑后账号降为普通用户并立即失效旧会话；队员档案、已登记演职员和历史资料保留，尚未审核的作品加入申请取消。管理员账号不能通过此入口解绑。
- 作品记录简介、年份、宣传短句、演员角色和后台分工；人员从已有队员档案中选择。
- 认证队员可在作品详情自由填写演员角色或后台分工并申请加入；管理员通过后写入演职员名单，驳回必须说明原因。
- 认证队员在作品档案页标题旁可直接“申请创建作品”；上传页仍保留缺少作品时的建档入口，两处都提交同一种结构化申请。
- 同一角色允许多名队员共同登记，作品页按角色归组并标记多人饰演或 AB 角；同一队员也能登记多个角色和多个后台分工。
- “同一队员 + 同一作品 + 同一类别 + 同一角色”不能重复；管理员审核同名角色时应看到现有人员，批准不会覆盖任何原记录。
- 管理员创建或编辑作品时，可将未归类的待审核或已入库 ARCHIVE 资料关联到作品；关联不会自动通过审核。
- 管理员删除作品前必须输入完整作品名确认；删除会清理演职员和加入申请，关联资料文件保留并转到“其他资料”。
- 封面只能从该作品已审核的剧照中选择，可选横版 16:9 或竖版 3:4。

## 资源与文件

- 管理员创建和编辑作品、指定演员与后台分工。
- 普通登录账号上传后人工审核。认证队员通过格式/大小/额度/身份校验的低风险资料直接入库；未知格式、疑似重复等转人工。管理员可撤销公开状态。
- 剧照可一次选择多张，每张独立保存并分别按规则审核；同一作品的已入库剧照集中显示为一块剧照画廊。
- 资料库按作品分区；未归类资料集中显示在“其他资料”。作品详情反向展示所有已入库关联资料。
- 资料库先显示作品分组，最后显示“其他资料”；组内以提交时间从新到旧排列。可按资料标题、说明、文件名或作品名搜索。
- 资料库和作品详情以预览卡片展示资料：图片使用轻量缩略图，视频使用自动截取画面，剧本、音频和其他文件使用专门设计的视觉封面；详情页恢复大图、视频、音频或文档入口。
- 待审核资料只能由提交人和管理员预览；审核通过后登录用户可预览和下载。
- 单个视频经常为 1–5GB，总量预计约 100GB；必须由浏览器分片直传 R2，不能经过 Worker 中转。
- 下载前由 Worker 检查登录、审核状态和权限。
