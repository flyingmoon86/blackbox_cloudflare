# 黑匣子 Cloudflare 迁移计划

更新日期：2026-09-09。

## 总目标

把 Flask + MySQL + 本地文件迁移为 TypeScript 单 Worker + D1 + R2。原 Python 网站保留在 `legacy-python/` 作功能对照，迁移完成并验证后再上线。

- [x] 建立正式 D1 初始表结构。
- [x] 建立 Hono 单 Worker、静态资源、安全响应头和统一错误处理。
- [x] 登录、退出、签名 Cookie、CSRF、旧 Werkzeug scrypt 密码兼容。

## 下一阶段

### 1. 资源记录与审核

- 迁移“作品内资料”和“其他资料”列表及详情。
- 认证队员提交资源元数据，状态默认为待审核。
- 管理员通过或驳回并填写说明。
- 先用测试对象键验证权限，不接真实大视频。

### 2. R2 大文件上传

- 创建测试 R2 Bucket。
- 实现 multipart 上传任务、断点续传、完成与取消。
- 校验 1–5GB 视频、并发、过期任务清理和失败恢复。
- 审核通过后才允许受控下载。

### 3. 剩余后台与页面

- 队员维护自己的简介、作品关联和头像。
- 管理员管理队员档案和资源。
- 帮助页面：登录用户看队员指南，管理员看管理员指南。
- 页面文案按页面编辑，编辑按钮跳到对应字段。

### 4. 数据迁移与云端测试

- 编写 MySQL 导出、转换和 D1 导入工具。
- 校验账号、队员、作品、关联、公告和资源数量。
- 创建独立测试 D1/R2、Cloudflare Secret 和测试域名。
- 大陆网络实测后确定域名与最终部署方案。

### 5. 上线

- 完成权限、安全、缓存、上传下载和备份检查。
- 冻结旧站写入，执行最终增量数据迁移。
- 验证后切换域名；保留旧站和备份作为回退。

## 暂缓和取消

- 邮箱验证与密码找回：用户选择暂缓，域名和邮件方案确定后实施。
- 奖项与演出季：用户决定不开发。
