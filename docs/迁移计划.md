# 黑匣子 Cloudflare 迁移计划

更新日期：2026-09-09。

## 总目标

把 Flask + MySQL + 本地文件迁移为 TypeScript 单 Worker + D1 + R2。原 Python 网站保留在 `legacy-python/` 作功能对照，迁移完成并验证后再上线。

## 正在进行：Cloudflare 正式上线

用户已在 2026-09-09 恢复云端部署计划，并说明已有域名。代码端准备已经完成；下面仍需 Cloudflare 账号中的真实资源和最终域名信息。

### 1. 数据迁移与云端测试

- 使用只读账号导出真实旧 MySQL，并检查转换警告。
- 在独立测试 D1/R2 导入真实数据，核对数量、外键与缺失文件。
- 创建正式 D1/R2、Cloudflare Secret，并把实际资源 ID、Bucket 名和域名填入 `wrangler.jsonc` 的 `env.production`。
- 配置 R2 CORS，用真实 1–5GB 视频验证直传、并发、中断恢复和失败重试。
- 先用正式域名做少量内部账号验收，再在中国大陆不同网络实测登录、图片和视频。

### 2. 上线

- 完成权限、安全、缓存、上传下载和备份检查。
- 首次上线前运行 `npm run deploy:check`，迁移 D1、配置 R2 CORS并部署。
- 若要迁移旧站真实数据，冻结旧站写入后执行最终导出和导入；当前没有真实用户数据时可直接从空库开始。
- 运行 `npm run smoke:production` 并按验收指南检查；原 Python 站和备份继续保留作回退。

## 暂缓和取消

- 邮箱验证与密码找回：域名已经具备，但邮件服务商仍未确定；正式邀请队员前需要决定是先接入自助找回，还是由管理员临时处理遗忘密码。
- 奖项与演出季：用户决定不开发。
