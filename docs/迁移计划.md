# 黑匣子 Cloudflare 迁移计划

更新日期：2026-09-10。

## 总目标

把 Flask + MySQL + 本地文件迁移为 TypeScript 单 Worker + D1 + R2。原 Python 网站保留在 `legacy-python/` 作功能对照，迁移完成并验证后再上线。
