# 黑匣子 · Version 1.0

一个为大学话剧队打造的作品与队员档案网站，记录演出、保存资料，也让新朋友认识剧团。

在线访问：[npublackbox.online](https://npublackbox.online/)

管理员入口：[admin.npublackbox.online](https://admin.npublackbox.online/)，使用现有管理员账号登录。

## 可以做什么

- **看作品**：每部戏一张卡片，进入后查看不同年份的演出版本、演员、后台分工与相关资料。
- **认识队员**：浏览个人档案、参与作品，给喜欢的队员送花，登录送花显示姓名与累计数量。
- **分享资料**：上传剧照、剧本和音频，支持预览、搜索与下载；作品资料按演出版本归档，剧照在作品内查看。
- **了解剧团**：查看公告、招新和网站贡献者。
- **管理网站**：审核申请、整理档案，编辑页面文案、背景、海报和主题色。

游客可以浏览公开内容。上传和下载需要登录；认证队员的低风险资料自动入库，普通账号提交后由管理员审核。测试阶段暂不开放视频上传和邮箱自助找回密码。

## 用什么搭建

全站使用 **TypeScript + Hono**，运行在一个 **Cloudflare Worker** 中。页面由服务端生成，CSS 和浏览器 JavaScript 负责样式与交互，适配电脑和手机。

- **D1 数据库**：保存账号、作品、演出版本、演职员和资料信息。
- **R2 文件存储**：保存上传的图片和文件，由网站检查权限后提供访问。
- **Static Assets**：提供样式、脚本和静态图片。

全站运行在 Cloudflare 上，不需要 Python 或独立服务器。

## 本地运行

安装 Node.js 24 或更新版本，在项目目录打开终端：

```powershell
npm ci
# 仅第一次、且没有 .dev.vars 时复制；已有配置不要覆盖
Copy-Item .dev.vars.example .dev.vars
npm run db:init
npm run dev
```

打开 [http://127.0.0.1:8787](http://127.0.0.1:8787)。本地数据与线上独立，`db:init` 只升级本地数据库，不清空已有内容。

账号准备和具体检查步骤见 [本地验收指南](docs/本地验收指南.md)。

## 文件在哪里

```text
src/             页面、接口、权限和业务逻辑
public/          样式、浏览器脚本和静态图片
migrations/      数据库增量升级
scripts/         开发、测试与发布工具
docs/            验收指南和发布记录
design-proposal/ 美术与动效改造方向稿（静态 demo + 移植指南）
```

依赖、运行数据和私有备份不提交 Git。页面修改约定集中在 [网站优化 Skill](.agents/skills/blackbox-optimize/SKILL.md)。

## 检查与发布

```powershell
npm run deploy:check
```

检查通过后，按 [验收指南中的发布步骤](docs/本地验收指南.md#手动发布)备份、迁移并部署。**推送 GitHub 不会自动上线**；只有明确决定发布时才更新正式网站，不能用本地数据库覆盖线上数据。

最近发布的版本、测试结果与数据核对见 [验证记录](docs/验证记录.md)。
